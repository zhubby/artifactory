# Artifactory 界面设计规范

采用 Linear 的工作布局与快捷操作、Notion 的留白和内容层级。工作顺序为「项目 → 构建 → 交付」。界面使用中性色，让运行状态和用户内容承担视觉重点。

## 颜色与主题

| 语义 | 浅色 | 深色 |
| --- | --- | --- |
| 页面背景 | `#FFFFFF` | `#151515` |
| 侧栏背景 | `#F7F7F7` | `#191919` |
| 主要文字 / 主按钮底色 | `#202020` | `#EDEDED` |
| 主按钮文字 | `#FFFFFF` | `#151515` |
| 分隔线 | `#E8E8E8` | `#2E2E2E` |
| 次要文字 | `#686868` | `#A1A1A1` |
| 成功 | `#217346` | `#89CFA3` |
| 警告 / 运行中 | `#8B6508` | `#E3BF78` |
| 失败 / 危险操作 | `#B4232D` | `#F29B9B` |

颜色变量集中于 `web/src/styles/tokens.css`，组件使用语义变量。成功、警告、失败同时显示图标与文字；构建和发布分别呈现状态。Artifactory 名称和 assembly A 标志沿用现有资产，应用内使用单色。

浏览器图标使用 `#202020` 深灰底与 `#FFFFFF` 白色 A，与浅色主题的品牌标志一致。`web/src/app/icon.svg` 保留小尺寸轮廓，`favicon.ico` 从该 SVG 导出 16、32、48px，确保浏览器选择任一格式时配色相同。

`artifactory-theme` 保存 `system`、`light`、`dark`，默认跟随系统。控制台与文档共享这一偏好，并响应其他标签页的修改。语言保存在 `artifactory-locale` Cookie，中英词条必须成对更新。偏好切换不重新挂载业务页面。

## 字体与尺寸

- 本地 Inter Variable；中文回退到 PingFang SC、Microsoft YaHei 和系统无衬线字体。
- 日志、命令、哈希、机器标识使用本地 IBM Plex Mono。
- 正文基准 14px / 1.5；页面标题 22–24px / 1.35；节标题 13–16px；元数据 11–12px。
- 以 4px 为间距基准；常规圆角 4–6px，对话框 8px。使用细分隔线和轻量背景变化表达层级。
- 桌面主按钮高 32px，表单输入高 36px；手机交互目标至少 44px。

字体通过 npm 的固定版本随构建打包，不依赖外部字体服务。文档构建及本地 mdBook 预览都会准备相同字体资产。

## 工作框架与导航

桌面侧栏 240px，顶栏最小高度 48px。租户切换器位于顶栏，与面包屑、快捷搜索和页面操作组合。项目切换器只在项目侧栏顶部出现。租户侧栏提供项目、构建节点和租户设置；项目侧栏提供概览、构建、制品、发布和授权的项目设置。

设置使用原侧栏呈现分区，替换业务导航。设置内容不包含第二列纵向导航。租户设置按基础、构建与交付、访问与安全、危险操作分组；项目设置包含基本信息、成员、资源与凭据、签名默认值和归档与删除。普通租户成员只显示访问令牌。侧栏入口遵循现有权限，不能扩大资源或签名授权。

两个切换器只选择工作范围。租户菜单提供「查看全部租户」，设置和返回工作台使用侧栏入口。文档位于侧栏底部。账号入口位于桌面侧栏底部、手机顶栏右侧；租户大厅使用右上角账号入口。个人菜单仅提供个人设置和退出，设置覆盖面板保留业务上下文，默认进入资料分区，并提供安全和偏好分区。

`⌘/Ctrl K` 打开导航面板，搜索当前工作区的业务与授权设置，并保留可访问项目的切换入口。项目工作区不混入租户节点或租户设置。方向键、Home / End 选择结果，Enter 跳转，Escape 关闭并恢复焦点。当前列表筛选保持独立。项目切换在构建、制品、发布列表间保留栏目，在详情、创建和设置页回到目标项目概览。

1024px 以下侧栏变为抽屉；关闭时内容不进入键盘焦点顺序。抽屉限制焦点、锁定背景滚动，Escape 先关闭内部切换器，再关闭抽屉。768px 以下顶栏的租户选择器与面包屑分行，内容单列，表格在自己的容器内横向滚动。

短视口中，项目切换器固定在项目侧栏顶部，下面的导航独立滚动；切换菜单的结果列表也受视口高度约束。搜索框按向下键进入首项、向上键进入末项；Home / End 在搜索框中保留文本光标操作。快捷导航的项目名作为次要信息截断，始终保留可读的操作名称。个人设置的关闭按钮固定可见，表单内容在面板内滚动。

## 页面与组件

- 项目、构建、制品、发布使用紧凑列表、统一工具栏、筛选和行操作。项目概览优先显示进行中、失败项和最近发布。
- 构建引导在 Release 详情内使用四步弹窗：「源码 → 构建要求 → 交付目标 → 确认」。项目与版本只读；常用目标使用原生制品、容器镜像与平台卡片，精细合同在高级设置展开。高级参数位于确认步，返回编辑保留回答，最终确认才创建构建。
- 构建详情为「执行 / 计划 / 制品」。紧凑标题显示构建编号、版本和状态；源码、提交和耗时作为辅助信息。完整目标合同默认折叠。
- 设备使用资源行，详情在宽侧面板中展示。设置分区由工作区侧栏直接进入；内容区保留表单、只读限制和生命周期确认。
- 按钮、字段、列表工具栏、Tabs、Dialog / Drawer、表格、空状态、加载和错误反馈由共享组件提供。
- 制品表与下载入口只显示文件名，正式交付名称优先；完整路径用于搜索与内部识别。
- 登录、注册、邀请、租户选择、404 和错误页使用同一套字体、颜色与控件。文档保留 mdBook 目录、搜索、Mermaid 和匿名访问。
- 租户选择使用紧凑卡片，桌面双列、手机单列。卡片主链接扩大点击区域，管理链接独立，搜索与创建入口保持可见。

构建弹窗的步骤导航和底部操作固定，正文独立滚动。每步进入时聚焦问题标题，摘要提供具名修改入口。手机保留四步顺序，卡片按视口收缩，不产生页面横向滚动。提交期间禁用编辑、重复提交和关闭；失败保留回答。Release 或项目变为不可构建时，弹窗保留草稿并说明原因。

## 构建方案与执行

解析、规划、修订和待补充信息时，首次进入计划标签。
失败或取消且未创建任务时，首次进入计划标签。
其余状态首次进入执行标签。
轮询和状态变化保留用户已选标签。
切换标签保留日志 DOM、滚动位置与 SSE 订阅。

计划先显示规划状态、版本数、模型调用和 Tokens。
待补充问题与回答入口紧随状态，轮询保留草稿。
方案摘要默认最多四行，展开后逐字呈现原文。
原始构建要求、证据、外置脚本和审计默认折叠。
审计按需读取，保留分片合并、分页和终态补读。

1024px 及以上使用 240px 目标导航与详情双列。
1024px 以下使用共享目标下拉与单列详情。
原生目标显示平台、制品匹配规则和编号顺序步骤。
第一步默认展开，其他步骤按需展开。
命令保留缩进，提供复制与有边界的滚动区域。
镜像目标直接显示镜像名、平台、Dockerfile、上下文和构建池。
镜像参数与额外配置按需展开。
目标之间独立执行，界面不推断依赖图。

版本下拉显示版本号、时间与当前标记。
默认跟随构建的 `current_plan_id`。
构建与历史响应暂未同步时，保留可用方案并提示同步状态。
显式选中的历史版本不被轮询覆盖。
历史版本复用结构化方案，完整 JSON 只在高级信息中显示。
执行状态按任务和尝试的 `plan_revision_id` 对齐。
当前版本标明沿用成功目标的来源版本。
历史版本不显示当前任务进度。

## 设备名称与识别

设备列表使用三层信息。
主标题显示已保存的设备名称。
身份行显示不同于名称的主机名、系统、架构和八位节点 ID。
硬件行显示系统报告的型号、CPU 和内存。
缺失项省略，重复信息去重，不猜测营销型号。
完整名称通过可访问文字保留，长文本不得挤压行操作。

新注册默认使用系统主机名，管理员可自定义名称。
注册后名称保持稳定，主机名变化只更新辅助信息。
详情标题附近提供重命名入口与独立保存、取消操作。
“使用当前主机名”只填写草稿，保存后才生效。
缺少主机名时禁用该动作并显示原因。
名称去除首尾空白，拒绝空值、控制字符和超过100个 UTF-8 字节。
后台刷新保留编辑草稿，失败保留输入并使用顶部通知。
只读范围不显示编辑入口。

网络信息位于详情，按接口展示 IPv4 和 IPv6 地址。
同时显示采样时间和截断状态，离线保留最近快照。
地址用于连接诊断，设备身份以节点 UUID 为准。
列表复用批量摘要，不按卡片读取元数据或遥测。

## 设备详情层级

详情保留最大宽度 760px 的右侧面板。
标题和五个标签固定，正文独立滚动。
标题呈现名称、状态和授权的重命名入口。
状态紧随名称，重命名使用具名图标按钮。
手机保留至少 44px 的按钮触控区。
副标题呈现不同于名称的主机名、系统、架构和节点池。

概览先呈现型号、CPU、物理内存和任务槽位。
摘要使用一个中性背景，不为各项创建卡片。
网络地址、加速器和标签跟随摘要。
更多硬件信息、完整身份和原始数据默认折叠。
普通字段以标签和值对齐，完整地址和 ID 可换行。
可选空字段省略；必要字段缺失显示“未知”。
零值和布尔值保留，不能作为空值删除。

资源先显示采样状态和三个主要指标。
内存负载、磁盘、网络和加速器分别分组。
内存负载在宽屏成对对齐，手机逐行显示。
会话 ID、接收时间和丢弃批次放入采样诊断。
工具链使用单列工具行，版本和可用状态直接可见。
已上报的工具路径通过折叠区展开。
元数据普通值直接展示，复杂 JSON 和快照信息按需展开。
运维按升级、节点配置、运行诊断和危险操作排序。
升级版本复用对齐字段，分区内不重复分隔线。
运行诊断默认折叠，危险操作位于底部。

详情标题 18px，正文 13px，辅助标签 12px，主要指标 20px。
分区使用 24px 间距，区内使用 8px 或 16px 间距。
手机采用全宽面板，摘要和主要指标改成单列。
宽表格只在各自容器内横向滚动。
轮询保留展开状态、阅读位置与编辑草稿。

展示组件按概览、资源、工具链和运维拆分。
入口组件只组合标题、导航和数据生命周期。
设备详情样式集中于 `web/src/styles/node-detail.css`。
保留既有请求、权限、通知、骨架和弹窗焦点流程。

## 下拉与选择控件

所有下拉的触发器和弹层均使用应用自定义样式。
此规则覆盖桌面、手机、匿名页面和登录后的控制台。
禁止显示浏览器或操作系统的原生选择菜单。
只给原生 `select` 加边框或 `appearance: none` 不符合规范。
禁止使用原生 `datalist` 提供建议列表。

| 用途 | 共享实现与行为 |
| --- | --- |
| 表单单选、筛选、排序、语言和主题 | 使用 `ui/select.tsx` 的 `Select`，触发器展示当前选项，弹层展示选项与选中标记 |
| 可编辑引用与建议 | 使用 `ui/combobox.tsx` 的 `Combobox`，输入允许自由文本，建议选择使用自定义列表 |
| 租户、项目切换与操作菜单 | 保留已有自定义菜单，沿用相同颜色、尺寸、焦点和边界规则 |

触发器沿用输入框的背景、细边框和 5px 圆角。
右侧使用统一下箭头，长选项在触发器内截断。
弹层使用主题卡片背景、细边框和轻阴影。
高亮项使用中性背景，选中项显示勾选标记。
禁用项不可选择，并保留可读文字。
桌面控件高至少 36px，手机触控目标至少 44px。
1024px 以下，认证页将偏好下拉收进独立面板。
偏好入口与顶部通知不得互相遮挡。
弹层与完整输入框等宽，左右边缘对齐。
前置图标位于同一个触发器边框内。
长选项换行，不得撑宽弹层。
视口空间不足时，弹层收缩并避开边缘。
长列表在弹层内部滚动。
弹窗内的下拉必须显示在当前弹窗上方。
下拉不得被表格、面板或抽屉的溢出裁切。

固定选项遵循 combobox/listbox 语义。
字段必须具有可访问名称、展开状态和当前选择。
方向键移动选项，Home / End 跳转首尾。
Enter 或 Space 确认，Escape 只关闭当前下拉。
可编辑输入保留文字光标的 Home / End 行为。
输入法组合期间不得确认或改写选项。
关闭菜单后恢复合理焦点；按 Tab 能继续表单操作。
点击外部关闭菜单，不能误提交表单。
减少动态效果时禁用弹层入场动画。

共享选择控件保留 `name`、`value`、`defaultValue`、
`disabled`、`required` 和表单重置语义。
空选项必须提交空字符串，不能提交内部映射值。
异步候选到达后保留用户已经输入或选定的值。
隐藏的原生字段只用于表单提交与校验。
它不能触发原生菜单或成为重复的辅助技术入口。
必填校验失败时，将焦点交给可见触发器。
选择变更必须触发既有表单变更与未保存保护。

新增页面直接复用共享组件，禁止再实现原生下拉。
验收覆盖键盘、空值、禁用、必填、异步选项和弹窗嵌套。
同时检查深浅主题、手机布局和长列表的视口边界。

## 加载反馈

首次数据读取使用匹配内容的骨架：卡片、列表、表格、详情、表单或日志。加载说明只供屏幕阅读器读取，容器设置 `aria-busy`。已有数据在刷新时保留；请求失败后停止骨架，错误通过顶部通知反馈。

前台请求和页面导航共用顶部 2px 主题色细线，延迟 150ms 显示。多个请求全部结束后到达末端并淡出，等待期间不显示真实百分比。定时轮询和 SSE 不触发顶部进度条。生命周期后台任务不占用请求进度；全站不展示操作历史或阶段面板，恢复操作保留在归档与删除设置中。

## 状态、动效与可访问性

所有字段保留可访问名称；Tabs 使用方向键与 Home / End；弹窗和抽屉使用焦点约束与关闭后的焦点恢复。错误包含说明文字，危险操作保留既有确认和权限校验。长名称、路径和原始日志不得撑宽页面。

菜单、弹窗和状态切换使用 120–180ms 过渡；骨架在读取期间轻微脉动，顶部细线在请求等待期间缓进。动画默认开启，不提供用户开关，不读取旧动效存储值。`prefers-reduced-motion` 禁用骨架脉动和进度缓动，不显示提示。页面不包含背景画布、光晕、网格或持续装饰动画。

居中弹窗用 `translate` 定位，入场动画只改变 `transform` 和透明度，避免覆盖居中偏移。动效验收必须开启动画并检查起始、中间与结束帧，不能仅检查动画结束后的截图。

可访问性检查结合 Playwright 行为测试、axe 的 WCAG A / AA 自动检查及截图审阅。自动检查不能替代实体触屏、屏幕阅读器和不同浏览器的人工验收。

## 维护入口

设计变量在 `web/src/styles/tokens.css`；共享业务样式在 `components.css`；单选浮层样式在 `dropdown.css`；工作框架在 `workspace.css`；构建引导在 `wizard.css`；构建详情在 `build-detail.css`。基础控件从 `web/src/components/ui/` 导出，建议列表样式位于同目录的 `combobox.module.css`。`globals.css` 仅负责导入、Tailwind 语义映射、基础样式和减少动态效果规则。

界面重构沿用现有 API、可读 URL、租户与权限模型，不需要数据库迁移。请求取消、迟到响应拒绝、未保存保护和 SSE 生命周期继续由原有业务层维护。
