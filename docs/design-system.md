# Artifactory 界面设计规范

控制台与独立原型共用 Prism 设计语言。完整交付见[设计入口](https://github.com/zhubby/artifactory/blob/main/design-system/artifactory/README.md)。[Apple Liquid Glass 准则](https://github.com/zhubby/artifactory/blob/main/design-system/artifactory/APPLE-LIQUID-GLASS.md)是最高视觉原则。本文记录真实控制台的实现合同；[MASTER](https://github.com/zhubby/artifactory/blob/main/design-system/artifactory/MASTER.md)定义共同视觉基线。

界面范围依次为「账户 → 工作空间 → 项目 → 版本 → 构建」。中文界面统一使用「工作空间」。底层租户隔离、API 名称和既有 URL 保持原义。视觉不能扩大权限、补造数据或增加不存在的操作。

内容使用 Standard 稳定珠光表面。导航、重要工具组和临时浮层使用 Regular Glass。钴蓝强调当前动作，语义色解释状态。装饰光学层不折射正文。

| 语义 | 浅色 | 深色 |
| --- | --- | --- |
| 页面背景 | `#F3F5F8` | `#101319` |
| 内容表面 | `#FFFFFF` | `#1C212A` |
| 主要文字 | `#17243B` | `#EDF3FF` |
| 强调色 / 主按钮底色 | `#2459E0` | `#A4BAFF` |
| 主按钮文字 | `#FFFFFF` | `#112245` |
| 内容分隔线 | `#D7DFEC` | `#3B475A` |
| 交互边界 | `#7E8DA6` | `#8FA3C0` |
| 次要文字 | `#53627A` | `#B0BFD4` |
| 成功 | `#146C50` | `#85E2BD` |
| 警告 / 排队 | `#86520A` | `#F6D18B` |
| 执行中 / 信息 | `#2459B8` | `#B5CEFF` |
| 失败 / 危险操作 | `#B5263E` | `#FFAFBC` |

颜色变量集中于 `web/src/styles/tokens.css`，组件使用语义变量。成功、警告、失败同时显示图标与文字；构建和发布分别呈现状态。Artifactory 名称和 assembly A 标志沿用现有资产，应用内使用单色。

浏览器图标保留 `#202020` 深灰底与 `#FFFFFF` 白色 A。这是独立品牌资产，不随界面强调色变化。`web/src/app/icon.svg` 保留小尺寸轮廓，`favicon.ico` 从该 SVG 导出 16、32、48px，确保浏览器选择任一格式时配色相同。

`artifactory-theme` 保存 `system`、`light`、`dark`，默认跟随系统。控制台与文档共享这一偏好，并响应其他标签页的修改。语言保存在 `artifactory-locale` Cookie，中英词条必须成对更新。偏好切换不重新挂载业务页面。

## 材质与光学层

| 层级 | 使用范围 | 表达 |
| --- | --- | --- |
| Canvas | 页面背景 | 低饱和静态环境色 |
| Standard | 指标、项目、设备、图表、表格、表单和日志 | 稳定阅读底、轻珠光与柔阴影 |
| Regular Glass | 侧栏、顶栏、重要工具组、菜单和模态外壳 | 读取背景的功能层 |
| Clear Glass | 媒体控件与独立光学实验 | 少量使用，不作业务阅读底 |
| Prominent | 页面主要动作 | 强调色背景与明确文字 |

Regular 外壳使用 `blur(10px) saturate(210%)`、30px 大圆角、1px 色散薄边、顶部弧光与深柔阴影。浅色内高光为 `inset 0 1px 1px rgba(255,255,255,.95)`，深色降至 `.26`。这些数值是 Prism 的 Web 参数，不是 Apple 的固定参数。

同组工具共用一层背景滤镜。内部按钮不重复模糊。内容卡片不变成独立玻璃透镜。长表单与全高侧面板提高不透明度，正文保持稳定阅读面。对比不足时先提高不透明度，不靠增加模糊弥补。

色散限制在边缘，弧光不覆盖文字。雕塑只用于认证、大厅、空态或展示，不成为虚构业务对象。降低透明度时使用实体底；减少动态时独立关闭运动。

## 字体与尺寸

- 本地 Inter Variable；中文回退到 PingFang SC、Microsoft YaHei 和系统无衬线字体。
- 日志、命令、哈希、机器标识使用本地 IBM Plex Mono。
- 阅读正文 16px / 1.6；紧凑业务正文与控件 14px；元数据 11–12px。全局页面标题为 32px，手机为 28px；组件标题与认证页按场景调整。
- 以 4px 为间距基准。内容圆角 24px，玻璃外壳 30px，菜单 20px，输入 12px，按钮使用胶囊。内外圆角按间距递减。
- 共享桌面按钮为 36px，紧凑按钮为 32px。输入至少 44px；筛选至少 40px。触摸控件至少 44px。认证输入和提交为 52px，手机输入字号至少 16px。

字体通过 npm 的固定版本随构建打包，不依赖外部字体服务。文档构建及本地 mdBook 预览都会准备相同字体资产。

## 工作框架与导航

桌面侧栏宽 236px，距视口边缘 16px。顶栏最小高度 64px，独立悬浮于内容上方。主内容最大宽度 1600px。工作空间切换器位于顶栏，与面包屑、快捷搜索、文档和通知组合。项目切换器只在项目侧栏顶部出现。工作空间侧栏提供概览、项目、节点池、共享设备和工作空间管理；项目业务导航提供概览与版本，管理入口按授权显示。

设置使用原侧栏呈现分区，替换业务导航。设置内容不包含第二列纵向导航。工作空间设置按基础、构建与交付、访问与安全、危险操作分组；项目设置包含基本信息、成员、资源与凭据、签名默认值和归档与删除。普通工作空间成员只显示访问令牌。侧栏入口遵循现有权限，不能扩大资源或签名授权。

两个切换器只选择工作范围。工作空间菜单提供「查看全部工作空间」，设置和返回工作台使用侧栏入口。顶栏的通知铃铛位于文档右侧。宽度至少为 1024px 时，工作空间的账户入口位于侧栏底部。窄屏工作空间、大厅和完整通知页的账户入口位于铃铛右侧。个人菜单仅提供个人设置和退出，设置覆盖面板保留业务上下文，默认进入资料分区，并提供安全、偏好和通知分区。

`⌘/Ctrl K` 打开导航面板，搜索当前工作空间的业务与授权设置，并保留可访问项目的切换入口。项目范围不混入工作空间设备或设置。方向键、Home / End 选择结果，Enter 跳转，Escape 关闭并恢复焦点。当前列表筛选保持独立。项目切换在构建、制品、版本列表间保留栏目；从版本内部详情切换时回到目标项目版本列表，其他详情、创建和设置页回到目标项目概览。

1024px 以下侧栏变为抽屉；关闭时内容不进入键盘焦点顺序。抽屉限制焦点、锁定背景滚动，Escape 先关闭内部切换器，再关闭抽屉。768px 以下全局工具保持一行，文档使用图标，面包屑另起一行。内容单列，表格在自己的容器内横向滚动。

短视口中，项目切换器固定在项目侧栏顶部，下面的导航独立滚动；切换菜单的结果列表也受视口高度约束。搜索框按向下键进入首项、向上键进入末项；Home / End 在搜索框中保留文本光标操作。快捷导航的项目名作为次要信息截断，始终保留可读的操作名称。个人设置的关闭按钮固定可见，表单内容在面板内滚动。

## 页面与组件

- 页面操作位于当前页面标题区。注册节点、新建项目、创建工作空间、新建版本、编辑说明、构建与发布均不进入全局顶栏。手机按钮在标题下方排列。
- 项目关注只在项目概览的名称旁显示五角星。空心表示未关注，实心表示已关注。选中状态使用主要文字色，并保留可访问名称、选中语义和失败重试。星标继续控制项目通知订阅。
- 工作空间大厅卡片进入 `/tenants/:slug/projects`。工作空间切换和创建完成进入同一项目目录。目录提供搜索、生命周期筛选、排序与卡片/列表视图。两层概览使用完整窗口指标、趋势和近期活动，不从截断列表推算统计。
- 构建引导在 Release 详情内使用四步弹窗：「源码 → 构建要求 → 交付目标 → 确认」。项目与版本只读；常用目标使用原生制品、容器镜像与平台卡片，精细合同在高级设置展开。高级参数位于确认步，返回编辑保留回答，最终确认才创建构建。
- 构建详情为「过程 / 执行 / 计划 / AI 审计 / 制品」五个标签，首次固定进入过程。过程展示真实当前动作、五阶段状态和持久记录。标题显示构建编号、版本和状态；源码、提交和耗时作为辅助信息。完整目标合同默认折叠。
- 设备使用 Standard 资源卡片，详情在宽侧面板中展示。设置分区由工作空间侧栏直接进入；内容区保留表单、只读限制和生命周期确认。
- 按钮、字段、列表工具栏、Tabs、Dialog / Drawer、表格、空状态、加载和错误反馈由共享组件提供。
- 制品表与下载入口只显示文件名，正式交付名称优先；完整路径用于搜索与内部识别。
- 登录、注册和邀请共用品牌雕塑与珠光认证表单。真实认证使用用户名；注册保留配置开关、确认密码和 UTF-8 字节校验。密码显隐使用独立 44px 按钮，保留密码管理器、键盘操作与自动填写。
- 工作空间大厅使用桌面双列、手机单列 Standard 卡片。主链接进入项目目录，管理链接独立，搜索与创建入口保持可见。只呈现已有授权身份与数据，不制造最近访问或邀请统计。404、错误页和文档沿用字体与语义控件；文档保留 mdBook 目录、搜索、Mermaid 和匿名访问。

工作空间与项目概览共用等宽 Standard 图表。内容宽度至少 780px 时并排展示，并对齐标题和绘图区。更窄时纵向排列。构建结果使用绿、玫瑰、蓝灰和赭色；周转趋势使用钴蓝。图例、提示与文字摘要共用语义。无样本时，空态替代绘图区与坐标轴。

柱体上下使用相同圆角，半径随实际高度收敛。渐变不改变零基线、总量和分段高度。微小非零值保持圆角，不以最小高度或宽度放大。折线使用 `monotoneX`、圆线端和圆连接，缺失样本断开，孤立点保留。当前生产图表关闭重复绘入动画，刷新直接更新真实数据。

构建弹窗的步骤导航和底部操作固定，正文独立滚动。每步进入时聚焦问题标题，摘要提供具名修改入口。手机保留四步顺序，卡片按视口收缩，不产生页面横向滚动。提交期间禁用编辑、重复提交和关闭；失败保留回答。Release 或项目变为不可构建时，弹窗保留草稿并说明原因。

## 列表筛选

搜索、状态和排序保持同一行，控件间距为 8px。
搜索框随可用宽度伸缩，下拉文字使用省略号。
搜索图标和下拉箭头保持固定尺寸。
桌面筛选至少高 40px，手机统一至少高 44px。
项目目录和工作空间选择的搜索框使用同一尺寸。
概览时间范围下拉使用同一高度。

结果计数在桌面右对齐，手机单独右对齐。
可用宽度不足时，仅筛选条横向滚动。
筛选不得折行，也不得撑宽整个页面。
滚动区域保留焦点轮廓的空间。
键盘聚焦时，控件滚动到可见位置。
下拉弹层通过 Portal 显示，不受筛选条裁切。
通知中心的类型、工作空间和项目复用单行规则。
表单下拉保留原有宽度，不受筛选布局影响。

## 构建方案与执行

构建首次统一进入过程标签，包括失败、取消和未创建任务。
过程按真实记录解释状态，并提供计划与审计入口。
轮询和状态变化保留用户已选标签。
切换标签保留日志 DOM、滚动位置与 SSE 订阅。

计划先显示规划状态、版本数、模型调用和 Tokens。
待补充问题与回答入口紧随状态，轮询保留草稿。
方案摘要默认最多四行，展开后逐字呈现原文。
原始构建要求、证据和外置脚本默认折叠。

1024px 及以上使用 240px 目标导航与详情双列。
1024px 以下使用共享目标下拉与单列详情。
原生目标显示平台、制品匹配规则和编号顺序步骤。
第一步默认展开，其他步骤按需展开。
命令保留缩进，提供复制与有边界的滚动区域。
镜像目标直接显示镜像名、平台、Dockerfile、上下文和构建池。
镜像参数与额外配置按需展开。
目标之间独立执行，界面不推断依赖图。

版本下拉显示版本号、时间与当前标记。
默认跟随构建的 `current_plan_id`。
构建与历史响应暂未同步时，保留可用方案并提示同步状态。
显式选中的历史版本不被轮询覆盖。
历史版本复用结构化方案，完整 JSON 只在高级信息中显示。
执行状态按任务和尝试的 `plan_revision_id` 对齐。
当前版本标明沿用成功目标的来源版本。
历史版本不显示当前任务进度。

## AI 审计

AI 审计是计划后的独立标签，使用 Standard 阅读表面。
首次进入才读取会话与消息，切离暂停轮询。
切回静默补读，保留轮次、动作、详情标签与阅读位置。
轮次导航显示序号、用途、开始时间与状态。
选中轮次补充模型和已记录的结束时间。
Run ID、Pod UID 与源码摘要位于技术信息中。

摘要只统计已加载原始记录、工具与提案、待关注动作。
搜索匹配已加载动作的标题、主题、工具名与调用 ID。
共享下拉筛选全部、工具与提案、消息和待关注。
待关注包括失败、拒绝、不完整分片和终态未记录结果。
搜索与筛选保留当前证据，分页入口继续可用。
计数不代表全会话总量，不推算 Token 用量。

动作列表与详情分区阅读，平台提示独立折叠。
可读结果、参数和原始记录使用详情标签。
复制始终取选中动作的原始记录，与当前详情标签无关。
复制成功或失败统一使用顶部通知。
手机提供详情与动作列表的双向跳转，同时滚动并转移焦点。
分片只在完整且一致时合并，缺失结果不得推造成功。

## 设备名称与识别

设备列表使用三层信息。
主标题显示已保存的设备名称。
身份行显示不同于名称的主机名、系统、架构和八位节点 ID。
硬件行显示系统报告的型号、CPU 和内存。
缺失项省略，重复信息去重，不猜测营销型号。
完整名称通过可访问文字保留，长文本不得挤压行操作。

新注册默认使用系统主机名，管理员可自定义名称。
注册后名称保持稳定，主机名变化只更新辅助信息。
详情标题附近提供重命名入口与独立保存、取消操作。
“使用当前主机名”只填写草稿，保存后才生效。
缺少主机名时禁用该动作并显示原因。
名称去除首尾空白，拒绝空值、控制字符和超过100个 UTF-8 字节。
后台刷新保留编辑草稿，失败保留输入并使用顶部通知。
只读范围不显示编辑入口。

网络信息位于详情，按接口展示 IPv4 和 IPv6 地址。
同时显示采样时间和截断状态，离线保留最近快照。
地址用于连接诊断，设备身份以节点 UUID 为准。
列表复用批量摘要，不按卡片读取元数据或遥测。

## 设备详情层级

详情保留最大宽度 760px 的右侧面板。
标题和五个标签固定，正文独立滚动。
标题呈现名称、状态和授权的重命名入口。
状态紧随名称，重命名使用具名图标按钮。
手机保留至少 44px 的按钮触控区。
副标题呈现不同于名称的主机名、系统、架构和节点池。

概览先呈现型号、CPU、物理内存和任务槽位。
四项摘要使用同组 Standard 珠光分区，按统一间距排列。
网络地址、图形设备和标签跟随摘要。
更多硬件信息、完整身份和原始数据默认折叠。
普通字段以标签和值对齐，完整地址和 ID 可换行。
可选空字段省略；必要字段缺失显示“未知”。
零值和布尔值保留，不能作为空值删除。

资源先显示采样状态和三个主要指标。
CPU 利用率与已用内存的分钟趋势位于当前指标下方。
宽屏图表等宽并排，手机纵向排列。
趋势默认近 1 小时，可选近 15 分钟或 6 小时。
刷新趋势会读取截至当前分钟的窗口。
相邻采样用单调曲线连接。缺失分钟保留断点。
内存负载、磁盘、网络和图形设备分别分组。
图形设备按设备 ID 匹配硬件清单，优先显示型号。
GPU 利用率和已用显存缺失时显示“未上报”。
内存负载在宽屏成对对齐，手机逐行显示。
会话 ID、接收时间和丢弃批次放入采样诊断。
工具链使用单列工具行，版本和可用状态直接可见。

## 下拉与选择控件

所有下拉的触发器和弹层均使用应用自定义样式。

禁止显示浏览器或操作系统的原生选择菜单。
只给原生 `select` 加边框或 `appearance: none` 不符合规范。
禁止使用原生 `datalist` 提供建议列表。

触发器沿用输入框的背景、细边框和 12px 圆角。

## 加载反馈

首次数据读取使用匹配内容的骨架：导航、卡片、列表、表格、详情、表单或日志。加载说明只供屏幕阅读器读取，容器设置 `aria-busy`。侧栏等待当前工作空间权限时保留品牌、上下文与菜单分组的占位。骨架不包含可点击导航。已就绪的导航在切换页面和后台刷新时保留。

数据区域区分未返回、空列表和失败。必要选项返回后才挂载可提交表单。请求失败后停止骨架，错误通过顶部通知和重试入口反馈。已有内容与草稿在轮询期间保留，不因全局请求计数重新显示骨架。

前台请求和页面导航共用顶部 2px 主题色细线，延迟 150ms 显示。多个请求全部结束后到达末端并淡出，等待期间不显示真实百分比。定时轮询和 SSE 不触发顶部进度条。生命周期后台任务不占用请求进度，恢复操作保留在归档与删除设置中。通知中心呈现结果提醒，构建详情集中呈现真实阶段和动作记录。

从顶栏铃铛打开通知中心。桌面使用 440px 抽屉，移动端使用全屏面板；完整筛选进入 `/notifications`。外壳使用 Regular，通知正文保持稳定阅读底。语义图标与文字共同表达状态。未读同时使用圆点和文字权重。抽屉、详情与设置遵循键盘、焦点恢复和减少动效偏好，见[通知中心](notifications.md)。

## 状态、动效与可访问性

所有字段保留可访问名称；Tabs 使用方向键与 Home / End；弹窗和抽屉使用焦点约束与关闭后的焦点恢复。错误包含说明文字，危险操作保留既有确认和权限校验。长名称、路径和原始日志不得撑宽页面。

共享动效使用 120ms 快速反馈、200ms 状态过渡与 280ms 浮层入场。功能外壳在精细指针进入时单次流光，悬停胶囊在同组导航间连续移动。认证雕塑和大厅内容允许分组单次入场。事件结束后停止装饰运动；没有空闲装饰循环。

骨架只在读取期间脉动，顶部细线只在请求等待期间缓进。数值立即显示最终值，图表不得通过补点或插值虚构事实。动效默认开启，不提供持久化开关，不读取旧动效存储值。

`prefers-reduced-motion` 关闭位移、缩放、流光和骨架脉动。降低透明度改用实体底；增强对比提高边界；forced-colors 使用系统颜色。三项偏好独立响应，不借减少动态强制改变透明度或主题。

居中弹窗用 `translate` 定位，入场动画只改变 `transform` 和透明度，避免覆盖居中偏移。动效验收必须开启动画并检查起始、中间与结束帧，不能仅检查动画结束后的截图。

可访问性检查结合 Playwright 行为测试、axe 的 WCAG A / AA 自动检查及截图审阅。自动检查不能替代实体触屏、屏幕阅读器和不同浏览器的人工验收。

## 维护入口

设计变量在 `web/src/styles/tokens.css`，材质在 `prism-material.css`。工作框架在 `workspace.css` 与 `prism-workspace.css`。认证、大厅、项目和设备分别使用 `prism-auth.css`、`prism-tenants.css`、`prism-projects.css` 与 `prism-devices.css`。概览图表在 `dashboard.css`，设备详情在 `node-detail.css`。共享业务样式在 `components.css`，下拉在 `dropdown.css`，构建引导在 `wizard.css`，构建详情在 `build-detail.css`。事件触发光学层由 `prism-interactions.tsx` 提供。

基础控件从 `web/src/components/ui/` 导出，建议列表样式位于同目录的 `combobox.module.css`。`globals.css` 只负责导入、Tailwind 语义映射、基础样式和减少动态效果规则。独立原型与生产代码分别维护，通过设计规范和真实合同同步，不能把演示数据当作 API 能力。

界面重构沿用现有 API、可读 URL、租户与权限模型，不需要数据库迁移。请求取消、迟到响应拒绝、未保存保护和 SSE 生命周期继续由原有业务层维护。
