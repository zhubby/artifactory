# 构建过程与源码诊断

## 目标与边界

构建首先展示过程，明确当前阶段和阻塞原因。
保留计划、执行日志和制品三个详情入口。
复用现有构建、规划与执行历史。
只为源码新增有界、可持久读取的阶段记录。
历史缺失明确显示，不推造旧事件。

## 后台合同

源码阶段为授权、引用解析、提交固定、仓库检查和清单提交。
记录包含服务端时间、执行尝试、动作和结果。
进度请求复用 Pod、CR UID 与当前执行围栏。
事件重放幂等；取消和旧执行不能追加记录。
每任务最多保存 256 条源码事件。
失败分类为超时、DNS、连接、认证、TLS、引用和未知。
Git stderr 只供分类，不写入数据库、日志或响应。
响应不包含凭据、代理地址和进程环境。
未知异常保留安全摘要，不暴露错误链。

过程接口复核租户与项目读取权限。
过程包含创建、源码、规划、计划确认、分配、步骤和归档。
原生与镜像执行使用各自持久身份。
步骤保留重试和修订历史。
最近事件有界读取，并明确显示截断。

## 页面合同

沿用中性色、细分隔线和现有状态图标。
首屏依次显示当前结果、阶段顺序和最近动作。
记录说明动作、执行位置、时间及结果。
细节按需展开，窄屏不撑宽页面。
未进入阶段显示“尚未开始”。
失败后不再显示“解析中”。
源码失败明确说明 AI 与构建设备未启动。
制品归档与正式 Release 发布使用独立状态。
首读骨架，后台刷新静默，终态补读后停止轮询。
轮询保留用户标签、展开状态和滚动位置。
支持中英文、明暗主题和屏幕阅读器。

## 验收与部署

测试错误分类和凭据不外泄。
测试重放、执行围栏、取消和权限隔离。
测试源码失败、澄清、排队、修订和两类执行。
验证三个视口、键盘与 WCAG AA。
固定源码提交、镜像摘要和部署前身份。
备份数据库后执行兼容追加迁移。
更新 Control、Telemetry、Web 与源码准备镜像。
只配置已验证可达的池级出口。
保留旧记录，创建后续构建验证修复。
核对真实构建、制品摘要与线上页面。

本轮按用户指示跳过代理配置。
GitHub 网络限制单独记录，用真实失败构建验证诊断。
