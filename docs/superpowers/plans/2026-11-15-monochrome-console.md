## 约束

- 保留现有 API、URL、权限、租户隔离、归档/删除语义和数据模型，无数据库迁移。
- 保留真实 Git refs、草稿保护、空间切换请求取消、迟到响应拒绝和 SSE 订阅连续性。
- 明暗主题与中英文同步覆盖；正文 14px、标题 20–24px，侧栏 240px、顶栏 48px。
- 浅色背景 #FFFFFF、侧栏 #F7F7F7、文字 #202020、边框 #E8E8E8；深色对应 #151515、#191919、#EDEDED、#2E2E2E。
- 1024px 以下导航抽屉，768px 以下主内容单列与 44px 触控目标；状态不能只用颜色表达。
- 原始范围为本地实现与验证；用户随后明确要求「全部修复。然后 部署到 k8s」，本次包含现有 Kubernetes 的 Web 部署。没有执行 Git 提交、推送或合并。

## 验收

导航 / 项目切换、真实 refs 与构建请求、草稿保护、计划补充、SSE / 日志位置、取消 / 发布 / 下载、权限与生命周期、键盘与焦点、主题持久化和文档独立运行均需覆盖。测试服务必须使用本工作区的新构建；模拟 API 与真实后端证据分开记录。
