# 租户与项目工作台

登录后从 `/tenants` 进入独立租户大厅，搜索、创建和选择当前账号所属租户，查看角色、归档状态及账号操作记录。没有租户时可以创建租户或通过邀请加入。

## 空间与导航

| 空间 | 页面 |
| --- | --- |
| 租户大厅 | `/tenants` |
| 租户工作台：项目列表和近期活动 | `/tenants/{tenant}` |
| 共享设备 | 租户路径下的 `/nodes` |
| 租户管理 | 租户路径下的 `/settings/{section}` |
| 项目概览 | `/tenants/{tenant}/projects/{project}` |
| 项目构建、制品、发布 | 项目路径下的 `/builds`、`/artifacts`、`/releases` |
| 发起构建与构建详情 | 项目路径下的 `/builds/new`、`/builds/{number}` |
| 项目管理 | 项目路径下的 `/settings/{section}` |

租户管理包含基本资料、成员与邀请、共享资源、安全及生命周期；项目管理包含仓库与构建配置、成员、资源授权及生命周期。改名保持 slug 稳定。旧平级项目、构建、制品与发布页面已删除，不提供重定向。

顶部双级选择器均可搜索，支持方向键、Home、End 和 Escape。切换租户进入其项目首页；在构建、制品或发布列表切换项目时保留栏目，在详情、创建或设置页面切换时进入目标项目概览。选择器提供当前空间管理及返回全部项目的入口。

桌面使用随空间变化的单侧栏，宽度不足 1024px 时使用抽屉，限制焦点，Escape 关闭并返回触发按钮。手机切换器分行排列，右下角个人入口和内容留白适配安全区域。

业务请求、筛选、表单及订阅按租户和项目隔离，切换时取消旧请求并拒绝迟到响应。未保存表单离开时确认，包括链接、浏览器前进后退和刷新。个人设置覆盖业务页，不卸载业务组件或重启 SSE。

## 个人信息与设置

所有登录后的空间均提供右下角个人菜单：个人信息、个人设置、退出。设置面板包含资料、安全、偏好，手机使用全屏面板。

显示名称可修改，用户名只读，头像从名称生成。改密需要当前密码和两次相同的新密码，新密码为 12–256 UTF-8 字节。当前密码错误保留输入和登录状态；成功后注销账号全部会话并返回登录页。登录与改密使用同一用户行锁及密码哈希复核，阻止旧凭据验证结果创建新会话。

语言、主题和动效立即生效，沿用 Cookie／本地存储。匿名页面保留基础偏好入口。延续 IBM Plex、墨绿与香槟金双主题及单背景画布，系统减少动态效果优先。轮询、SSE 和偏好切换不会重播空间入场。

## 生命周期

租户所有者管理租户生命周期，管理员管理日常配置；项目管理员管理项目生命周期，设备和凭据授权仍由租户管理员负责。

归档及删除先排空：禁止新增构建和管理任务，等待已接受的构建、规划、上传、发布及相关设备升级结束。页面显示阻塞任务，可以进入构建详情另行取消，系统不会自动取消任务。归档后历史查询和下载可用；恢复租户不会恢复原本已归档的项目。

永久删除需要完整 slug 和当前密码，并展示影响数量。等待阶段可撤销；实际清理开始后只能查询进度或重试失败步骤。账号级操作记录在目标删除后继续存在。

PostgreSQL 持久队列使用租约、代次校验和幂等检查点，支持多副本接管。排空后保存清理清单，再清理 Source、Runtime、Telemetry、对象存储和控制库；外部 I/O 不占用数据库事务锁。上传授权过期并经过迟到写入宽限后重新清理。共享缓存及对象存在其他引用或在途导入时保留。

项目删除覆盖构建、日志、制品、发布、源码和 Runtime 历史；租户删除进一步撤销设备、Worker、邀请和 Token，清理遥测及共享配置。完成后保留最小操作审计及标识墓碑，阻止旧链接绑定新对象，已删除默认租户不会被启动逻辑重建。备份沿用现有保留策略。

## 迁移与验证

追加 Control `0005/0006`、Source `0001`、Runtime `0002` 和 Telemetry `0002` 迁移及 Toasty 快照。现有账号以用户名初始化显示名称，现有空间初始化为正常状态。升级需停写、备份并验证恢复，协调更新服务，不能将旧实例接回新库。

UI fixtures 验证交互与视觉；真实 PostgreSQL、S3 和 TimescaleDB 验证持久化、竞态、排空、接管及清理隔离。线上破坏性验收仅使用临时租户和项目，保留已有设备、持久卷及非目标资源，并记录实际执行项与 CI 边界。
