# 租户与项目工作台

登录后从 `/tenants` 进入独立租户大厅，搜索、创建和选择当前账号所属租户，查看角色、归档状态及账号操作记录。没有租户时可以创建租户或通过邀请加入。

## 空间与导航

| 空间 | 页面 |
| --- | --- |
| 租户大厅 | `/tenants` |
| 租户工作台：项目列表和近期活动 | `/tenants/{tenant}` |
| 构建节点 | 租户路径下的 `/nodes` |
| 租户设置 | 租户路径下的 `/settings/{section}` |
| 项目概览 | `/tenants/{tenant}/projects/{project}` |
| 项目构建、制品、发布 | 项目路径下的 `/builds`、`/artifacts`、`/releases` |
| 发起构建与构建详情 | 项目路径下的 `/builds/new`、`/builds/{number}` |
| 项目设置 | 项目路径下的 `/settings/{section}` |

租户工作台侧栏只显示项目、构建节点与租户设置。普通租户成员的设置入口为访问令牌。项目工作台侧栏显示概览、版本；有效角色为项目管理员时显示项目设置。版本工作台使用概览、构建记录、交付物页内标签。项目工作台不显示租户节点或租户设置。文档入口保留在侧栏底部。

租户切换器位于顶栏。项目切换器只在项目工作台侧栏顶部出现。两个切换器均可搜索，只用于选择工作范围。租户切换菜单提供「查看全部租户」，进入 `/tenants`。设置入口位于侧栏，返回入口位于侧栏当前工作区上方。

切换器支持方向键、Home、End 和 Escape；搜索框中的 Home、End 保留文本光标操作。切换租户进入目标租户的项目列表。在构建、制品或发布列表切换项目时保留栏目；在版本详情或版本内构建页面切换项目时进入目标项目版本列表；其他详情、创建或设置页面切换时进入目标项目概览。项目业务侧栏提供「返回租户工作台」。

打开设置后，同一侧栏替换为当前工作区的设置分区。页面只呈现所选分区标题与内容，不增加第二列纵向导航。设置侧栏提供返回当前工作台的入口。

| 工作区 | 设置分组与分区 |
| --- | --- |
| 租户管理员 | 基础：基本信息、成员与邀请；构建与交付：AI 规划、Emissary 自动升级、签名管理；访问与安全：访问令牌、Git 凭据、审计记录；危险操作：归档与删除 |
| 普通租户成员 | 访问与安全：访问令牌 |
| 项目管理员 | 基础：基本信息、成员与邀请；构建与交付：资源与凭据、签名默认值；危险操作：归档与删除 |

租户 `/settings` 默认显示基本信息，普通成员默认显示访问令牌。项目 `/settings` 默认显示基本信息。租户旧地址 `/settings/security` 继续显示访问令牌，`/settings/resources` 继续显示 AI 规划；侧栏高亮对应的规范分区。项目 `/settings/resources` 仍为资源与凭据。改名保持 slug 稳定。旧平级项目、构建、制品与发布页面不提供重定向。

桌面使用单侧栏。宽度不足 1024px 时使用抽屉，限制焦点，Escape 关闭并返回触发按钮。窄屏顶栏允许租户选择器与面包屑分行；个人入口位于右上角，页面内容不因长名称撑宽。

业务请求、筛选、表单及订阅按租户和项目隔离，切换时取消旧请求并拒绝迟到响应。未保存表单离开时确认，包括链接、浏览器前进后退和刷新。个人设置覆盖业务页，不卸载业务组件或重启 SSE。

## 个人信息与设置

工作台的个人入口位于桌面侧栏底部、手机顶栏右侧；租户大厅的入口位于右上角。个人菜单只提供个人设置和退出。打开个人设置默认显示资料，面板内还提供安全和偏好分区。手机面板使用横向分区入口和内部滚动。

显示名称可修改，用户名只读，头像从名称生成。改密需要当前密码和两次相同的新密码，新密码为 12–256 UTF-8 字节。当前密码错误保留输入和登录状态；成功后注销账号全部会话并返回登录页。登录与改密使用同一用户行锁及密码哈希复核，阻止旧凭据验证结果创建新会话。

偏好分区提供语言和主题，修改立即生效，沿用 Cookie／本地存储。匿名页面保留同一组偏好字段。界面采用中性色、本地 Inter 和 IBM Plex Mono。动画默认开启，不提供动效开关，也不读取旧 `artifactory-effects=off` 值。系统减少动态效果自动生效，不显示提示。轮询、SSE 和偏好切换不会重播空间入场。

## 生命周期

租户所有者管理租户生命周期，管理员管理日常配置；项目管理员管理项目生命周期，设备和凭据授权仍由租户管理员负责。

归档及删除先排空：禁止新增构建和管理任务，等待已接受的构建、规划、上传、发布及相关设备升级结束。页面显示阻塞任务，可以进入构建详情另行取消，系统不会自动取消任务。归档后历史查询和下载可用；恢复租户不会恢复原本已归档的项目。

永久删除需要完整 slug 和当前密码，并展示影响数量。等待阶段可撤销；实际清理开始后只能查询进度或重试失败步骤。账号级操作记录在目标删除后继续存在。

PostgreSQL 持久队列使用租约、代次校验和幂等检查点，支持多副本接管。排空后保存清理清单，再清理源码任务、规划协调器、Telemetry、对象存储和控制库；外部 I/O 不占用数据库事务锁。上传授权过期并经过迟到写入宽限后重新清理。对象存在其他引用或在途导入时保留。

项目删除覆盖构建、日志、制品、发布、源码和规划协调器历史；租户删除进一步撤销设备、Worker、邀请和 Token，清理遥测及共享配置。完成后保留最小操作审计及标识墓碑，阻止旧链接绑定新对象，已删除默认租户不会被启动逻辑重建。备份沿用现有保留策略。

## 初始化与验证

工作区字段、生命周期队列和审计均包含在当前全新实例基线中。业务数据库基线为 `2026112001`，规划数据库基线为 `2026111901`。程序拒绝旧库，不追加旧架构迁移，也不自动重置或删除已有部署。旧实例由管理员独立备份和退役，不能将旧实例接回新库。

UI fixtures 验证交互与视觉；真实 PostgreSQL、S3 和 TimescaleDB 验证持久化、竞态、排空、接管及清理隔离。线上破坏性验收仅使用临时租户和项目，保留已有设备、持久卷及非目标资源，并记录实际执行项与 CI 边界。
