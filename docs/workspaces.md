# 租户与项目工作台

登录后从 `/tenants` 进入独立租户大厅，搜索、创建和选择当前账号所属租户。卡片集中展示名称、角色、slug 和状态；桌面双列，手机单列。主链接覆盖卡片，管理链接独立且遵循权限。没有租户时可以创建租户或通过邀请加入。

## 空间与导航

| 空间 | 页面 |
| --- | --- |
| 租户大厅 | `/tenants` |
| 租户概览：统计、趋势和活跃项目 | `/tenants/{tenant}` |
| 全部项目：搜索和创建项目 | `/tenants/{tenant}/projects` |
| 构建节点 | 租户路径下的 `/nodes` |
| 节点池 | 租户路径下的 `/pools` |
| 租户设置 | 租户路径下的 `/settings/{section}` |
| 项目概览 | `/tenants/{tenant}/projects/{project}` |
| 项目构建、制品、发布 | 项目路径下的 `/builds`、`/artifacts`、`/releases` |
| 发起构建 | 项目 `/releases/{release}` 内的四步弹窗 |
| 构建详情 | 项目 `/releases/{release}/builds/{number}` |
| 项目设置 | 项目路径下的 `/settings/{section}` |

租户工作台侧栏显示概览、项目、构建节点、节点池与租户设置。普通租户成员的设置入口为访问令牌。项目工作台侧栏显示概览、版本；有效角色为项目管理员时显示项目设置。版本工作台使用概览、构建记录、交付物页内标签。顶栏文档右侧的通知铃铛显示未读数。账户入口在顶栏时，铃铛位于账户入口左侧。

租户切换器位于顶栏。项目切换器只在项目工作台侧栏顶部出现。两个切换器均可搜索，只用于选择工作范围。租户切换菜单提供「查看全部租户」，进入 `/tenants`。设置入口位于侧栏，返回入口位于侧栏当前工作区上方。

切换器支持方向键、Home、End 和 Escape；搜索框中的 Home、End 保留文本光标操作。切换租户进入目标租户概览。在构建、制品或发布列表切换项目时保留栏目；在版本详情或版本内构建页面切换项目时进入目标项目版本列表；其他详情、创建或设置页面切换时进入目标项目概览。项目业务侧栏提供「返回租户工作台」。

打开设置后，同一侧栏替换为当前工作区的设置分区。页面只呈现所选分区标题与内容，不增加第二列纵向导航。设置侧栏提供返回当前工作台的入口。

| 工作区 | 设置分组与分区 |
| --- | --- |
| 租户管理员 | 基础：基本信息、成员与邀请；构建与交付：AI 规划、Emissary 自动升级、签名管理；访问与安全：访问令牌、Git 凭据、审计记录；危险操作：归档与删除 |
| 普通租户成员 | 访问与安全：访问令牌 |
| 项目管理员 | 基础：基本信息、成员与邀请；构建与交付：资源与凭据、签名默认值；危险操作：归档与删除 |

租户 `/settings` 默认显示基本信息，普通成员默认显示访问令牌。项目 `/settings` 默认显示基本信息。租户旧地址 `/settings/security` 继续显示访问令牌，`/settings/resources` 继续显示 AI 规划；侧栏高亮对应的规范分区。项目 `/settings/resources` 仍为资源与凭据。改名保持 slug 稳定。旧平级项目、构建、制品与发布页面不提供重定向。

桌面使用单侧栏。宽度不足 1024px 时使用抽屉，限制焦点，Escape 关闭并返回触发按钮。窄屏全局工具保持一行，文档使用图标，面包屑另起一行；个人入口位于铃铛左侧，页面内容不因长名称撑宽。

页面操作留在当前标题区。注册节点、新建项目、新建版本、编辑说明、构建和发布不占顶栏。创建租户继续位于租户大厅内容区。项目概览名称旁以五角星切换项目关注。

首次进入、刷新或切换工作区时，等待权限的侧栏区域显示骨架。同一工作区内切换菜单保留已就绪导航。主内容按目标数据区域显示骨架，失败后提供重试。后台轮询保留已读内容与表单草稿。

业务请求、筛选、表单及订阅按租户和项目隔离，切换时取消旧请求并拒绝迟到响应。未保存表单离开时确认，包括链接、浏览器前进后退和刷新。个人设置覆盖业务页，不卸载业务组件或重启 SSE。

## 节点池

租户侧栏的“节点池”打开 `/tenants/{tenant}/pools`。
租户 owner/admin 可以创建和重命名节点池。
名称在租户内唯一，去除首尾空白后为 1–100 UTF-8 字节。
名称不接受控制字符。
成员只查看项目授权范围内的池与设备计数。
设备总数和在线数由服务端聚合，未从分页列表推算。

“查看设备”打开带池 ID 的构建节点列表。
节点池筛选与搜索、分页共同生效，刷新保留池 ID。
管理员在设备详情的配置中迁移设备所属池。
项目设置的“资源与凭据”授权项目使用节点池。

删除前必须移出设备并解除项目引用。
默认池和保留升级历史的池不能删除。
确认删除同时撤销该池的注册令牌。
注册正在使用令牌时，删除返回冲突且不改动池。
重命名和删除与审计在同一事务提交。
归档租户的节点池页面只读。

## 统计与构建活动

租户概览显示活跃项目数、构建次数、成功率和当前进行中构建。
项目概览用成功构建周转时长替换活跃项目数。
两层概览共用每日构建结果柱状图和周转中位数折线图。
默认近30天，支持7天和90天。统计按浏览器时区的自然日分桶。
顶部统计和图表由数据库聚合，不使用截断的构建列表推算。

构建结果按创建日归属，显示构建当前状态。
失败包含失败和失联，成功率排除取消及进行中构建。
周转时长包含规划、排队和执行，只取成功构建的中位数。
无成功样本的日期显示断点，不作为零耗时。
当前进行中统计不受所选时间范围限制。

活跃项目按构建创建或最终完成时间排序，每项目仅一行。
租户概览显示最近5个活跃项目，项目概览显示最近5次构建活动。
可见归档项目保留历史统计，物理删除的数据不追溯。
完整项目目录独立提供搜索和创建，不在概览重复列出。
概览首次读取使用骨架，每10秒静默刷新；刷新失败保留已读内容。

## 个人信息与设置

工作台的个人入口位于桌面侧栏底部；手机、租户大厅和完整通知页的入口位于顶栏铃铛左侧。个人菜单只提供个人设置和退出。打开个人设置默认显示资料，面板内还提供安全、偏好和通知分区。手机面板使用横向分区入口和内部滚动。

显示名称可修改，用户名只读，头像从名称生成。改密需要当前密码和两次相同的新密码，新密码为 12–256 UTF-8 字节。当前密码错误保留输入和登录状态；成功后注销账号全部会话并返回登录页。登录与改密使用同一用户行锁及密码哈希复核，阻止旧凭据验证结果创建新会话。

顶栏通知中心打开个人跨租户收件箱，`/notifications` 提供完整筛选与时间线。个人设置「通知」提供站内偏好、邮箱验证和邮件订阅；租户和项目设置「集成」提供管理员 Webhook。项目概览名称旁的星标可显式关注构建变化，详见[通知中心](notifications.md)。

偏好分区提供语言和主题，修改立即生效，沿用 Cookie／本地存储。匿名页面保留同一组偏好字段。界面采用中性色、本地 Inter 和 IBM Plex Mono。动画默认开启，不提供动效开关，也不读取旧 `artifactory-effects=off` 值。系统减少动态效果自动生效，不显示提示。轮询、SSE 和偏好切换不会重播空间入场。

## 生命周期

租户所有者管理租户生命周期，管理员管理日常配置；项目管理员管理项目生命周期，设备和凭据授权仍由租户管理员负责。

归档及删除先排空：禁止新增构建和管理任务，等待已接受的构建、规划、上传、发布及相关设备升级结束。系统不会自动取消任务。归档后历史查询和下载可用；恢复租户不会恢复原本已归档的项目。

永久删除需要完整 slug 和当前密码，并展示影响数量。请求接受后通过顶部通知反馈“已提交”。界面不展示操作历史、阶段或进度清单；“归档与删除”设置只为当前范围最近操作保留撤销等待或失败重试按钮。实际清理开始后无法撤销。账号级操作记录和查询、撤销、重试 API 继续保留。

PostgreSQL 持久队列使用租约、代次校验和幂等检查点，支持多副本接管。排空后保存清理清单，再清理源码任务、规划协调器、Telemetry、对象存储和控制库；外部 I/O 不占用数据库事务锁。上传授权过期并经过迟到写入宽限后重新清理。对象存在其他引用或在途导入时保留。

项目删除覆盖构建、日志、制品、发布、源码和规划协调器历史；租户删除进一步撤销设备、Worker、邀请和 Token，清理遥测及共享配置。完成后保留最小操作审计及标识墓碑，阻止旧链接绑定新对象，已删除默认租户不会被启动逻辑重建。备份沿用现有保留策略。

## 初始化与验证

工作区字段、生命周期队列和审计均包含在当前全新实例基线中。业务数据库基线为 `2026112101`，规划数据库基线为 `2026111901`。程序拒绝旧库，不追加旧架构迁移，也不自动重置或删除已有部署。旧实例由管理员独立备份和退役，不能将旧实例接回新库。

UI fixtures 验证交互与视觉；真实 PostgreSQL、S3 和 TimescaleDB 验证持久化、竞态、排空、接管及清理隔离。线上破坏性验收仅使用临时租户和项目，保留已有设备、持久卷及非目标资源，并记录实际执行项与 CI 边界。
