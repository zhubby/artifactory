## 实现

Git stderr 有界读取并持续排空，仅用于错误分类。
上游原文不进入错误消息、进度或公开过程接口。
源码任务保存授权、引用解析、提交固定、仓库检查和清单阶段。
每次写入复核 Pod、CR UID、执行尝试与业务终态。
服务端生成记录时间，重放不重复，旧执行被围栏拒绝。

`GET /api/v1/builds/{id}/activity` 复核当前租户和项目读取权限。
接口白名单聚合源码、规划、计划、设备、步骤和制品记录。
事件保留执行尝试、计划版本和目标归属。
最多返回最近 500 条，并标识截断。
旧源码历史缺失时不推测具体 Git 错误。

构建默认打开「过程」。
页面显示当前动作、五阶段状态与可展开后台记录。
日志、计划和制品入口保留。
终态无 SHA 显示「未固定提交」。
后台更新保留用户选择、展开状态和滚动位置。
