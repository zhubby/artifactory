# Artifactory 0.2.6

控制台采用 Prism 液态玻璃设计语言。
内容使用稳定珠光表面，导航和浮层使用功能玻璃。
交互流光与导航胶囊响应操作，空闲时停止装饰运动。
减少动态、降低透明度和强制颜色分别适配。

中文界面统一使用「工作空间」。
登录、注册、工作空间大厅和项目目录更新布局。
选择、创建或切换工作空间后进入项目目录。
目录提供授权项目的搜索、筛选、排序及双视图。
图表使用等圆角柱、渐变和保留缺失断点的柔和曲线。
设备、节点池、通知与构建页面共用同一设计基线。

设计交付包含规范、120项组件及独立产品原型。
原型使用演示数据，实际控制台继续使用既有 API。
工作空间权限、租户隔离和正式发布合同保持原有约束。
本版本没有数据库结构变更。

发布前审查修复了文档站点的三个设计入口链接。
这些文件位于源码设计目录，链接现在指向源码页面。
类型检查、生产构建与版本一致性检查通过。
定向浏览器回归29项通过。
完整浏览器回归和集群验收结果在部署记录中独立记录。

普通产品发行不包含原生设备的六平台签名 OTA 资产。
设备升级仍由管理员显式发起。
