## 发现并修复的问题

| 问题 | 实际表现 | 修复与永久回归 |
| --- | --- | --- |
| 项目设置取消无效 | 编辑名称、仓库等字段后点击取消，输入仍保留且继续触发未保存警告 | 取消时重新载入已保存的表单值；验证字段恢复和后续导航 |
| 子模块凭据操作漏记草稿 | 添加或移除关联后离开页面，不提示放弃修改 | 添加、移除都标记表单草稿；验证拒绝离开、确认离开和重新进入 |
| 退出失败没有反馈 | 断网后点击退出，出现未处理 Promise 拒绝，菜单没有重试反馈 | 捕获错误、在菜单展示、提交期间禁用按钮并允许重试；验证没有页面异常 |
| 放弃旧草稿后可漏掉新草稿警告 | 确认离开后很快进入另一表单，700ms 宽限期继续生效 | 宽限限定到同一 URL 和同一组草稿 DOM，新的页面和表单重新确认 |
| 文档源码编辑链接错误 | 首页、普通章节和嵌套章节均生成 `docs/docs/…` | 移除 URL 模板的重复目录；验证三种章节的准确仓库路径 |

新增 `web/tests/ui/browser-audit.spec.ts` 三个行为测试，并为文档补充源码链接测试。测试先在修复前的生产预览或部署页面失败，再在修复后通过；导航测试还覆盖连续操作时的新草稿保护。
