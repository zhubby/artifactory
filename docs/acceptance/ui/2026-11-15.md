# 全站 UX/UI 重构验收 · 2026-11-15

## 实现范围

按已批准的 Linear / Notion 方向，完成黑白灰设计变量、本地 Inter / IBM Plex Mono、240px 项目优先侧栏、48px 顶栏、面包屑与页面操作、权限限定的快捷导航、统一列表及反馈组件。

构建采用「源码 → 目标与平台 → 确认」三步引导；详情采用「执行 / 计划 / 制品」标签，保留日志 DOM、SSE 与滚动位置。设备改为资源列表及详情侧面板，设置改为分组导航；账号偏好继续覆盖业务页面。登录、注册、邀请、租户选择、404、错误状态与 mdBook 同步使用新体系。

控制台和文档默认跟随系统，使用同一明暗偏好并支持跨标签页同步。保留现有 URL、API、权限、租户隔离、未保存保护和空间切换的请求取消；没有数据库迁移。移除 Aurora、Spotlight、装饰画布、重复样式及闲置 GSAP 依赖。

设计细节见[界面设计规范](../../design-system.md)。实现位于本地 `codex/monochrome-console` 工作区；未提交、推送。后续复核与 Kubernetes 发布状态单独记录于文末。

## 核心链路的证据边界

| 流程 | 模拟 API 行为验证 | 隔离真实后端验证 |

## 复核命令

在本工作区的 `web/` 目录中运行：

```sh
rtk proxy npm run typecheck
rtk proxy env ARTIFACTORY_API_URL=http://127.0.0.1:35493 npm run build
rtk proxy env ARTIFACTORY_UI_PORT=32161 ARTIFACTORY_UI_PRODUCTION=1 npm run test:ui -- --workers=3
rtk proxy env ARTIFACTORY_DOCS_URL=http://127.0.0.1:32161 npm run test:docs
```

真实浏览器测试使用 `npm test`，从本地私有配置加载隔离后端的环境变量，并以 `ARTIFACTORY_BROWSER_EVIDENCE` 指向上述原生验收证据。不要把私有配置加入源码或公开报告。

## Code review 修复与发布复核

两个 P2 问题已补充永久行为回归。测试首先在修复前的生产预览中失败：个人设置打开时快捷导航抢走焦点；执行标签隐藏期间追加日志，再返回后距离日志末尾仍有 4559px。

修复为：个人设置和共享弹窗显式声明 `aria-modal`；全局 Cmd/Ctrl K 在其他可见模态窗口存在时保留当前焦点和窗口。执行标签重新可见时，启用跟随后滚动到最新日志，暂停跟随则保留阅读位置。新增测试同时验证快捷面板自身可以开关、设备面板不会被抢焦点，以及暂停日志的位置不变。

修复后的 TypeScript、生产构建、完整 UI 275 项和文档 12 项通过。文档主题测试补齐实际重载完成的等待，避免读取上一份文档已切换的类名后立刻发起新的媒体偏好操作。实际待发布的 linux/amd64 standalone 镜像另通过桌面 / 平板 / 手机共 6 项修复回归，以及 12 项文档测试。
