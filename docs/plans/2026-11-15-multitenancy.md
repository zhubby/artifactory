# 多租户实施记录

交付范围：源码、追加迁移、迁移工具、隔离环境验收，以及按用户授权修复全部审查问题、合并并推送 main、协调升级现有 K8s 的 `artifactory` 命名空间。

- [x] 租户、成员、邀请、所有权、设备授权与升级迁移
- [x] 账号认证和租户／项目授权分离，所有业务接口隔离
- [x] 调度、MCP、Worker、Runtime 和命令投递授权一致
- [x] 登录选择、创建／邀请引导、成员及项目设备权限界面
- [x] 数据库、安全回归、Worker、前端与浏览器验收
- [x] 协调升级、备份与恢复操作文档

关键约束：登录后总是选择租户；租户上下文来自每个页签的 URL；普通成员需要项目成员关系；Token 持续复查持有者权限；设备槽位按唯一节点共享；构建冻结授权与当前授权取交集。

## 实现与审查

- 控制库追加 `2026111501`、Runtime 追加 `2026111502`；保留既有迁移，更新 Toasty 投影快照和迁移历史检查。SQL 约束负责同租户关联、唯一所有者和设备授权快照。
- 业务请求通过显式租户上下文和实际成员关系授权。列表按可见项目查询，直接 ID、事件流、制品、遥测、OTA、凭证和模型分别校验；共享节点隐藏其他项目的运维诊断和任务内容。
- 节点池与指定设备授权分别保留。调度、MCP、重选和命令投递统一使用构建快照与当前项目范围的交集，并通过真实 PostgreSQL 节点行锁保护共享槽位。
- 项目配置及成员变更在事务内复查实际权限。租户管理使用 `FOR NO KEY UPDATE`，既串行化成员变更，也允许任务插入的外键锁；回归测试实际复现了原锁顺序的死锁并验证修复。
- 迁移保留旧构建已有的授权快照，包括空列表。维护排空检查覆盖构建、发布、规划、有效执行租约和 OTA；备份使用分块 SHA256 校验。
- 前端以租户 ID 重建页面，取消旧请求、轮询和事件流；构建操作权限根据详情中的项目 ID 判断，覆盖未出现在最近构建列表中的记录。

## 验收边界

隔离环境的三副本竞争验证使用三份独立调度状态与同一真实 PostgreSQL 数据库，验证多项目共享设备不超分槽位。未执行万台连接压测或集群故障演练。备份恢复验证覆盖数据库关系；既有对象存储保持原状。

## 审查修复与 K8s 交付

- 直接 ID 授权使用 Axum 匹配路由与已解码参数，避免百分号编码 UUID 绕过租户和项目检查。非法 UUID 拒绝，合法编码 ID 保持可用。
- 项目管理员不能保留已有根仓库凭证并将仓库改向其他地址。无凭证项目仍可修改仓库，租户管理员可重新授权带凭证仓库。
- 项目资源校验、凭证及模型归属检查复用当前事务连接，避免事务占满连接池时再等待额外连接。新增真实 PostgreSQL 回归覆盖仅剩一条连接的更新。
- 上述三个回归先在原实现全部失败，修复后通过。最终检查：fmt、Workspace 全 target/feature Clippy `-D warnings`、95 项默认 Rust 测试、控制库 78 项（不含设备集群负载用例）、Runtime 9 项、Telemetry 4 项、Worker 15 项、Python 35 项、Web 类型及生产构建、租户浏览器 33 项、文档和 Helm 检查通过。两个 Runtime 用例首次缺少测试服务令牌，补齐私有环境后单独重跑通过。
- 既有本机、AI、Compose 和 Operator 验收客户端显式使用隔离安装的默认租户；远端 AI 验收读取私有证据中的租户 ID。真实 API 浏览器验收改为注册后显式授予租户及项目只读权限，不再假设全局 viewer 能读取历史项目。验收客户端已在真实预览 API 验证从 `tenant_required` 恢复为成功；后续镜像源码的 Compose TLS CI 通过，本轮未重跑既有物理设备或 Operator 的完整构建链路。
- 部署镜像由 `deployment-images` 工作流从已提交源码生成，只发布 `sha-<commit>` 标签；不覆盖 `v0.2.0` 资产。集群使用校验后的不可变摘要。
- 源码 CI 另发现性能测试夹具未初始化租户及设备池授权，已先在真实隔离 PostgreSQL 复现，再修正夹具；控制平面库测试含该性能用例共 14 项通过，fmt 和 Clippy 通过。
- CI 数据库步骤补齐独立随机 Runtime 服务令牌，两个对应回归按相同环境重跑通过，actionlint 通过；完整 CI 的既有 SSH fixture 与 kind/kubeadm 环境失败单独保留记录。
- 现有集群已完成停写备份、追加迁移、独立数据库真实恢复验证及 Helm revision 3 升级。三个控制平面副本、原有设备和 Worker 在线，权限隔离与真实浏览器验收通过。恢复入口后完整观察 30 分钟，31 次采样全部通过、容器重启为零；4 个 PVC 和凭据／PKI 保留，139 项所选非目标资源未变化。完整现场结果见[多租户 Kubernetes 升级记录](../releases/2026-11-15-multitenancy-kubernetes.md)。
