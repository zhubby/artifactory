# 设备详情视觉与信息层级

## Problem Statement
设备详情把常用配置与低频技术字段放在同一层级。
用户要求保留侧面板，以美观和清晰为主要目标。

## Findings
概览先显示完整 ID，再显示硬件；固定两列造成长文本混排。
资源诊断、工具路径与元数据 JSON 默认占用正文。

## Proposed Solutions
保留五个标签，使用四项摘要、对齐字段和默认折叠的技术细节。

## Recommended Action
按已确认方案拆分展示组件，保留数据、权限和操作流程。

## Acceptance Criteria
- [x] 四项摘要先于网络与技术身份显示。
- [x] 资源、工具链、元数据和运维按用途分组。
- [x] 有效零值可见，低频信息可展开，轮询保留阅读状态。
- [x] 明暗主题与 320、390、820、1440px 布局通过截图和行为验证。
- [x] 类型检查、构建与相关回归通过，更新文件契约与模块地图。
