# 产品原型复核 · 2026-11-27

以 Apple Liquid Glass 最高准则为依据。
审查覆盖材质、信息层级、对象身份与操作反馈。
本轮修改独立原型，不修改现有 Web 控制台。

## 核心修正

| 范围 | 原问题 | 当前行为 |
| --- | --- | --- |
| 顶栏 | 旧尺寸与工具组不统一 | 64px整层Regular，内部搜索和工具不重复模糊 |
| 材质 | 降低透明仍残留背景模糊 | 装饰节点、遮罩和功能层分别关闭滤镜 |
| 认证 | 没有 main，跳转链接无目标，双 h1 | 四页提供主区域、单一 h1 与焦点入口 |
| 触摸 | 平板图标和导航不足44px | 平板、粗指针与认证辅助操作扩大命中区 |
| 键盘 | 手机宽表和阶段不能聚焦 | 仅实际溢出区域加入名称和滚动焦点 |
| 焦点 | 关闭手机导航后回到 body | Escape 与遮罩关闭回到菜单按钮 |
| 项目 | 页面有两个主要动作 | 页头保留主动作，进入版本改次级 |
| 项目快照 | 其他项目沿用Orbital的状态与数字 | 各项目读取自己的版本、构建和目标记录 |
| 项目筛选 | 筛选触发器与数量未同步 | 保留筛选值，数量来自当前列表 |
| 概览窗口 | 7天只改标签，图表仍是28天 | 窗口、柱数、日期、总数和成功率同步 |
| 概览数据 | 柱、说明和数据表各用不同数字 | 同一逐日源生成指标、分段、图形与表 |
| 耗时曲线 | 终点与4分32秒说明不一致 | 13个采样点共用分钟标尺，曲线不越界 |
| 设备 | 所有设备进入 Mac Studio | 稳定设备深链；缺失详情明确标注 |
| 采样 | 离线被当作0%，曲线与数据表不同源 | 缺失不绘零；12点曲线与数据表同源 |
| 观测 | 图例、柱色与取消结果不一致 | 三类结果同源，颜色、总数、纵轴和表一致 |
| 阶段 | 手机换行使28秒比186秒更长 | 各条共用0–186秒标尺 |
| 设置 | 成功提示后字段与false开关丢失 | 表单保存全部字段，回填本地状态 |
| 项目设置 | 项目间共用表单存储 | 按项目标识分别保存与回填 |
| 通知 | 筛选标签变化但列表不变 | 工作空间与类型组合过滤，保留明确空态 |
| 排空 | 有任务时写已排空 | 暂停接单、排空中与当前任务分别呈现 |
| 终端 | 没有退出，离开仍连接 | 显式断开，离开终端或设备后结束模拟会话 |
| 构建 | 不同构建全部进入1048 | 编号深链保留项目、源码与状态 |
| 构建入口 | 历史版本影响全局发起构建 | 先确定当前入口的项目与版本，再校验冻结 |
| 重新构建 | 1048默认丢失macOS amd64 | 固定原提交并恢复全部六个目标 |
| 向导 | 确认内容被固定示例替代 | 1049本地快照保留版本、ref、要求与目标 |
| 草稿 | 继续丢答案，放弃却保留 | 关闭前捕获当前步，放弃后清空草稿 |
| 版本 | 历史正式版本变成空草稿 | 正式版本保持冻结，缺失证据说明缺失 |
| 版本归属 | 无构建记录的Design Portal显示Orbital | 从项目索引恢复身份与冻结，缺失证据不猜测 |
| 取消 | 取消后仍提示排队恢复继续 | 运行与排队目标结束，成功目标保留 |
| 发布 | 已停止仍强制确认停止 | 活动状态决定确认项和检查图标 |
| 制品 | Windows/Linux显示macOS身份 | 文件、来源构建、校验方式与下载目标一致 |
| 镜像 | 各组件都打开同一个清单 | 按组件显示对应版本、架构与摘要缩写 |
| 布局 | 去玻璃后版本卡选择器失配 | 内容布局独立于材质类 |
| SemVer | 允许重复正式版本 | 校验格式和本地已有版本 |
