# 独立原型 AI 审计同步

范围：仅 design-system/artifactory/prototype。未修改生产 Web，未提交、未部署。

## 实现

- 轮次导航、会话身份、已加载记录摘要、动作列表与证据阅读层次与产品对齐。
- 功能筛选使用 Regular Glass；记录和证据使用 Standard 内容面。
- 搜索动作、文件、引用和调用标识，仅筛选已加载记录。
- 自定义下拉支持全部动作、工具与提案、消息正文、需要留意。
- 查询和筛选直接更新列表隐藏状态，不重建所选证据 DOM。
- 按轮次保留分页、所选记录、详情标签、查询、筛选和滚动位置。
- 支持可读结果、参数、原始记录，真实复制成功与失败顶部反馈。
- 手机提供所选详情和返回动作列表的滚动、焦点入口。
- 失败、中断、拒绝、缺失、消息分片、加载错误和预算提示使用本地显式演示样例。
- 缺失和不完整记录不补写结果；移除审计面板的固定调用与 Token 汇总。

## 验证

results.json：1440/375 × light/dark，共 4 组。每组均验证搜索保留证据 DOM/原始标签、筛选时继续分页、键盘筛选、轮次阅读保留、复制成功/失败、7 个异常场景。手机验证详情/列表焦点；横向溢出 0；审计区域 Axe WCAG A/AA 违规 0；页面错误 0。

reading-state.json：调用 ID 搜索、证据 scrollTop=80、轮次切换、构建标签切换和刷新后查询/所选证据保留。

preferences.json：默认工具栏 blur(10px) saturate(2.1)；减少透明度关闭模糊且控件可用；减少动态效果独立于材质；强制色彩保留动作。
