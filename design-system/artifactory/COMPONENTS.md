# Prism 组件规范

组件展厅覆盖 120 项独立标本，分为 12 类。本文保留 38 个核心模式的跨页面规则。完整标本规格分为三个分册；重叠模式不重复计入总数。

| 分册 | 组件分类 | 标本数 |
| --- | --- | --- |
| [输入与操作](COMPONENTS-INPUTS.md) | 操作、表单、选择、日期与文件 | 40 |
| [数据与导航](COMPONENTS-DATA.md) | 导航、数据、图形、内容 | 40 |
| [反馈与业务](COMPONENTS-FEEDBACK.md) | 反馈、浮层、交付、组织 | 40 |

交互入口为原型 `#design/components`。支持中英文搜索、分类筛选、密度切换与单项深链。每项组件标本演示一个主要交互；完整状态与使用边界由分册定义。

[120 项逐项审查](COMPONENT-AUDIT.md)记录原问题、实际改动、材质选择与验证范围。组件展厅按每项用途标注 Standard、Regular、Clear 或混合材质，分类名称不决定玻璃用法。当前精修仅作用于组件库。

[Apple 最高设计准则](APPLE-LIQUID-GLASS.md)约束全部 120 项标本。Standard 承载内容，Regular Glass 承载导航与重要功能层。标本外框、数据卡片、图表和日志不加液态滤镜。Clear Glass 只用于媒体上方控件与光学实验。

所有尺寸使用 CSS px。产品按钮默认36px、紧凑32px；输入44px、筛选40px。触摸目标至少44px。展厅专属尺寸以三个分册为准。状态矩阵为默认、悬停、按下、聚焦、禁用、加载、错误和成功；不适用的状态在组件内说明。

## 1. 按钮 Button

| 变体 | 视觉 | 用途 |
| --- | --- | --- |
| Primary | 钴蓝实体底，on-primary 文字，轻内高光 | 页面唯一主动作 |
| Secondary | 中性浅底，control-border，text 文字 | 并列次动作；重要独立工具可用 Regular |
| Ghost | 透明底，悬停 surface-soft | 返回、展开、行操作 |
| Danger | danger-bg 与 danger 文字；最终确认可用实体红 | 取消构建、撤销授权、删除 |

常规左右 18px、图文间距 8px、胶囊圆角 999px、文字 14/22 Medium。悬停增加底色强度；按下使用内影。聚焦显示 3px focus、2px offset。禁用保留可读文字并使用 disabled。加载保持原宽度，显示 spinner 与「正在创建」等动作词，防止重复提交。产品图标按钮36×36px，触摸扩展至44×44px。展厅图标目标48px。必须有 accessible name。

按下在 120ms 内反馈，释放在 360ms 内回弹。共享工具外壳中的按钮不重复模糊。接触反馈限制在控件边界，不影响文字和焦点。禁用与加载状态不触发装饰动效或重复提交。

## 2. 文本字段 Input

label 14/22 Medium，字段与 label 间隔 8px，helper 与字段间隔 6px。输入 16/24，左右 14px，圆角 12px。默认 surface 底与 control-border；聚焦加 3px focus。错误边界 danger，错误说明包含原因和修正方法。只读字段使用 surface-soft 和「只读」标签，区别于禁用。禁止 placeholder 代替 label。

## 3. 多行输入 Textarea

最小高度 128px，行高 26px，允许纵向伸展。构建要求显示示例和目标边界，字符计数只在接近上限时强调。版本说明与构建要求分别命名。保存失败保留全文。

## 4. 自定义单选 Select

触发器与 Input 同尺寸。右侧 16px chevron；弹层与触发器等宽、圆角 20px、最大高 320px。选项最小高 44px；选中显示勾选与文字权重。弹层通过 Portal 防止裁切。使用 combobox/listbox 语义，方向键、Home / End、Enter、Esc 与 Tab 可操作。禁止原生 select 菜单和 datalist。

内容表单触发器使用 Standard。导航中的范围选择可共享 Regular 外壳。文字弹层采用 Regular，并保证文字对比。弹层在 200ms 内从触发器方向展开；先确定位置与尺寸，不拉伸选项文字。

## 5. 可编辑建议 Combobox

在 Select 基础上提供文本输入。分支、Tag、手动引用使用分组候选。输入法组合期间不确认。异步候选到达时保留已有文本。加载、无结果与读取失败分别显示。自由输入必须在提交前解释解析结果。

## 6. 多选平台 Target Picker

卡片最小高 88px，图标 24px、主标题 16/24、系统架构 12/18。选中使用 primary-soft、2px primary 边界、勾选和 aria-pressed。不可用目标展示原因与恢复路径，不能静默隐藏。原生目标与 OCI 目标分组。高级 key、架构和后缀默认折叠。

## 7. 复选框与开关

复选框视觉 20×20px，点击区域至少 44px；label 与控件间隔 10px。允许 indeterminate，批量选择同时显示数量。开关用于即时可逆设置，字段文案说明开启结果。保存中禁用重复提交；失败回到原状态并提示。高风险设置使用独立保存按钮。

## 8. 搜索框 Search

常规高 44px、图标 20px、圆角 14px。全局搜索可采用 Regular，列表搜索使用 Standard 输入底。聚焦增加清晰轮廓，不靠反光提示输入状态。清除按钮提供 accessible name。输入 250ms debounce，搜索和筛选写入可分享状态。无结果显示当前关键字和清除筛选动作。全局搜索与当前列表搜索分别命名。

## 9. 工作空间切换器 Scope Switcher

顶部显示当前工作空间，项目侧栏顶部显示项目。触发器包含名称和 chevron。弹层提供搜索、最近项目、所属角色与「查看全部工作空间」。只切换范围，设置动作留在导航。切换前处理未保存草稿；切换后取消旧请求。

## 10. 主导航 Navigation

导航行高 44px、左右内边距 14px、圆角 12px、图标 20px。分组间隔 24px。当前项采用浮动玻璃胶囊、primary 文字、Medium 字重与 aria-current。胶囊用 FLIP 在 360ms 内衔接位置，导航文字保持稳定。深层详情保留父项高亮。徽标只显示需要注意的事项，不对所有页面添加计数。

## 11. 面包屑 Breadcrumb

14/22px，层级间距 8px。最后一级为当前页文本。长层级保留工作空间、项目和当前对象，折叠中间层至可操作菜单。手机允许两行，不能挤掉全局工具。

## 12. 标签导航 Tabs

标签高 44px，文字 14/22 Medium。选中项使用滑动玻璃胶囊，primary 文字与字重共同表达选择。胶囊在 360ms 内移动，内容在 240ms 内轻淡入。使用 tablist/tab/tabpanel，支持方向键与 Home / End。语义选择即时更新。切换保留子视图状态。标签名不因加载变化；计数位于独立小标签中。

## 13. 分段控制 Segmented Control

容器高 44px、圆角 14px、surface-soft 底。选中轨道使用玻璃透镜与轻阴影，在 360ms 内衔接位置。适用于近7天 / 30天 / 90天、列表 / 卡片等同层级选项。快速切换取消旧动效并呈现最新选择。不得替代带多层分组的导航。

## 14. 内容面板与玻璃外壳 Panel

内容面板使用 Standard 底色、细分隔与 24–32px 内边距。指标、图表、项目、设备与标本外框不使用折射、色散、追踪反光或倾斜。标题与正文间距 20px。内层分组不重复阴影与模糊。

只有浮动导航、重要工具组与临时任务外壳使用 Regular Glass。大外壳采用 30px 圆角、1px 细弱色散边、顶部弧光和 10px/210% 滤镜。内控件按间距使用同心圆角。以上参数是 Prism 的 Web 选择，不是 Apple 固定参数。

## 15. 指标卡 Metric

最小高度 140px，label 14/22，数值 32/40，比较值 12/18。趋势包含箭头与文字。点击进入确切数据范围，并显示可点击提示。没有样本显示「暂无数据」，不能填充演示趋势到真实视图。

同组卡片保持稳定，可轻淡入一次。图表路径和进度条按需首次绘入。数值立即显示最终值，不播放虚构计数。

组件库图形复用独立几何层，不改动产品页面。折线采用保形曲线与 3px 圆端线，柱体上下采用相同圆角和纵向渐变。环形比例使用圆端弧，小分段收窄为短胶囊，容量仪表使用 180° 圆端弧。精确值保留在中心读数、图例或数据表。详细规则见 `COMPONENTS-DATA.md` 第 21–28 项。更新过渡 650ms，减少动态效果时直接呈现最终状态。

## 16. 项目卡 Project Card

包含项目名、稳定标识、仓库、累计构建、最近构建与生命周期。版本只在版本目录呈现。名称为主链接，独立菜单不嵌套在链接内。关注星标只在明确的项目上下文使用，提供按下状态。卡片使用 Standard 底色，悬停加强边界，不倾斜。布局与点击范围保持稳定。手机显示具名「打开项目」链接。

## 17. 表格与资源行 Data Table

表头 12/18 Medium，行正文 14/22。普通行高至少 60px；带两层信息为 76px。单元格横向 20px。仅数字右对齐。表头排序提供 aria-sort。整行链接有明确主链接，行菜单保持独立。选中行使用 primary-soft。批量选择后显示操作工具栏与计数。

手机转为记录卡，保留名称、主状态、关键值和行操作。必要宽表仅自身滚动。悬停不能成为发现操作的唯一方式。分页说明总数与当前范围，保留筛选。

## 18. 状态标签 Status Badge

高 26px、左右 10px、圆角 8px、12/18 Medium，图标 14px。成功、失败、排队和运行中使用对应语义底色与文字。禁止只显示彩色圆点。静态标签不接受焦点；可点击筛选标签使用 button 语义。

## 19. 筛选标签 Filter Chip

高 32px、圆角 999px、左右 12px。已选项包含字段名、值和清除按钮，例如「状态：失败」。标签集合先换行，不能压缩文字。超出收进可操作「另有 3 项」，展开可查看全部。清除后焦点移到相邻标签或筛选入口。

## 20. 工具提示 Tooltip

最大宽 280px、14/22px、内边距 10–12px、圆角 12px。延迟 400ms，键盘聚焦立即可见，Esc 关闭。内容不能是完成任务必须阅读的唯一说明。包含链接或按钮时使用 Popover。

## 21. 菜单与 Popover

最小宽 200px、圆角 20px、内边距 6px、选项高 44px。危险动作置底并加分隔线。打开后聚焦合理选项，Esc 关闭并恢复触发器焦点。点击外部关闭不误触下层动作。嵌套浮层先关闭最上层。

外壳采用玻璃透镜，密集选项补稳定阅读底。进入用 200ms 淡入与轻移，焦点不等待动效结束。

## 22. 模态框 Dialog

确认框宽 480px，编辑框宽 640px，向导宽 880px；最大高 `min(90dvh, 900px)`。圆角 30px，标题和底部操作固定，中部滚动。提供具名关闭和取消。限制焦点与背景滚动，关闭后返回触发器。提交中阻止重复提交。未保存内容关闭前展示具体丢失对象。

产品进入用280ms缓出，轻移4px并收敛至最终位置。展厅保留自身弹性标本。关闭立即恢复焦点与背景状态；无交互快照在 180ms 内淡出。快照不包含可聚焦节点，不进入辅助技术树。

## 23. 侧面板 Drawer

详情宽 760px，通知宽 440px；手机全屏。面板标题和标签固定，正文自然滚动。主页面保留上下文。设备终端等长期工作转为专属页面，避免多层抽屉。关闭前处理草稿和终端连接。

玻璃外壳在 360ms 内进入，正文保持稳定底色。关闭语义即时执行，180ms 退出只作用于无交互装饰快照。

## 24. 构建向导 Wizard

固定四步：源码 → 构建要求 → 交付目标 → 确认。步骤顶栏高 64px，底栏最小高 76px。当前步骤用编号、名称和 active 状态；已完成步骤可返回。项目与版本只读。每步校验后前进；最终一步才创建构建。确认页提供每组「修改」入口，修改后回到确认。失败保留草稿。

步骤状态即时更新，正文在 280ms 内淡入。切换先保存答案与最终步骤，再播放装饰动效。回退不重置已填字段。

## 25. 构建阶段 Stage Timeline

主阶段为源码准备、AI 规划、等待设备、执行构建、校验制品。每阶段包含状态、开始时间、耗时与当前动作。缺少记录显示「暂无阶段记录」。并行目标分行呈现，不推造目标依赖。取消后显示已完成动作和停止原因。

阶段状态变化触发一次有限高光。进度长度只由已知数据决定，不使用装饰循环暗示任务推进。

## 26. 目标矩阵 Target Matrix

行是平台目标，列是准备、编译、签名和上传；不适用步骤明确标记「无需签名」。阶段单元显示图标、文字与可打开的尝试记录。目标整体成功与 Release 发布分别呈现。手机按目标展开，支持「上一个 / 下一个目标」按钮。

## 27. 日志查看器 Log Viewer

稳定深色底或主题配对实体底，IBM Plex Mono 13/22。工具栏提供目标、尝试、搜索、复制和自动跟随。行号使用弱化中性色；错误同时有文本标记。用户向上滚动时暂停跟随，显示「返回最新」按钮。订阅断开保留日志并显示重连。敏感字段不进入演示数据。

## 28. AI 计划卡 Plan Card

先显示结论、版本、模型、预算与证据，再显示命令和脚本。动作使用「查看依据」「回答问题」「重新规划」。计划与执行状态分离；历史计划不显示当前进度。AI 建议不能默默更改目标或发布正式标签。建议修改通过确认摘要呈现差异。

## 29. 制品与证据 Artifact

主行显示正式文件名、平台、大小、校验状态与下载动作。二级详情包含完整 SHA256、源码提交、签名者和来源构建。复制后顶部 notify 反馈。镜像使用 OCI Index 与架构列表，不能把单架构摘要当多架构根摘要。

## 30. 发布确认 Release Confirmation

展示选中构建、源码、目标数量、文件摘要和不可变说明。所有目标必须来自同一完整成功构建。确认时冻结所选成功构建，其他构建保持独立状态。发布后替换为固定摘要与下载入口；失败只提供相同内容重试。不可提供「覆盖版本」操作。

## 31. 设备卡与详情 Device

主标题为已保存名称；身份行呈现主机名、系统、架构与短 ID；硬件行展示报告型号、CPU 和内存。离线保留最后采样。详情顺序为概览、资源、工具链、元数据、运维。资源缺失显示未上报。升级是管理员显式动作，版本差异只提示。

设备图标使用平静的分组底色。可交互卡片沿用项目卡的稳定边界反馈。设备操作工具组可用 Regular Glass。离线状态保留清晰文字，不用持续脉冲表示在线。

## 32. 顶部通知 Notify

位置为顶部居中、距安全区域 20px、最大宽 520px。图标 20px，正文 14/22，内边距 14px，圆角 16px。成功 4 秒自动关闭；失败持续显示并提供重试。`role=status` 或合适 live region，不抢焦点。通知出现不改变页面高度。

玻璃外壳在 200ms 内淡入。通知语义即时发布，不等待动效。连续通知合并或依序替换，避免叠加多个运动重心。

## 33. 收件箱 Notification Inbox

行高至少 88px，展示事项、项目、状态和时间。未读使用圆点与文字权重。多个阶段合并为同一事项时间线。分类、工作空间、项目、未读筛选可组合。读取详情前复核当前访问权。无权限摘要移除业务名称和链接。

## 34. 骨架与顶部进度 Loading

骨架形状匹配最终内容，容器 aria-busy，说明供辅助技术读取。无交互占位。顶部细线高 2px、延迟 150ms。后台刷新不遮盖内容。减少动态效果时骨架静态。请求失败停止骨架并显示恢复入口。

## 35. 空态、失败与无权限 Empty / Error

局部空态最小高 220px，SVG 48px、标题 18/26、说明16/26、单一下一步。失败保留已有内容，说明原因并提供重试；无权限说明所需角色和返回。找不到对象与网络失败使用不同文案。不可用动作不隐藏原因。

## 36. 危险确认 Destructive Confirmation

明确显示对象名、影响范围、可撤销边界和最终动作。取消构建需要确认任务影响；永久删除要求完整 slug 与当前密码。按钮标注「永久删除项目」等具体结果。不得用泛称「确定」代替。已提交操作通过 notify 反馈，结果进入账户收件箱。

## 37. 终端会话 Terminal

终端有设备名、会话状态、连接时长、断开按钮和权限说明。仅 owner/admin 原登录 Session 可进入，设备默认关闭终端。授权超时与连接断开分别显示。离开前提示连接状态；断开后不保留可执行输入。原型只模拟输出，不执行 Shell。

## 38. 设计检视器 Design Inspector

展示颜色、字阶、间距、圆角、玻璃材质和组件状态。展示顶部弧、色散边、透镜、接触涟漪与胶囊切换。支持明暗切换和减少透明度预览。token 名可复制，展示原型所用示例状态。此入口属于原型交付工具，不占正式产品业务导航。

## 液态交互规则

业务状态先更新，装饰动效后播放。快速连续操作取消旧动画并清理装饰节点。焦点、关闭与提交结果不依赖动画完成事件。路由轻淡入每次进入只播放一次，内容位置与阅读顺序稳定。

精细指针悬停才追踪重要功能层的反光。内容卡片不倾斜。页面隐藏、指针离开和节点移除后停止追踪。触摸保留按下反馈；键盘保留清晰焦点。空闲时没有常驻光学动画。

减少动态效果时直接显示最终状态。减少透明度时使用实体底，关闭反光、折射、色散与模糊。两种偏好分别生效，不能用关闭透明度代替关闭动效。

## 组合规则

新页面先划分内容层与功能层，再选择布局和组件。禁止为单一页面重新定义按钮、输入和模态。页面使用统一 notify、自定义 Select 和主题 token。卡片内的卡片使用 Standard 次分组。同类工具共享玻璃背景，不层层叠加。语义状态先写文字，再选择图标和颜色。

当实现与规格存在差异，在原型 README 中记录交付范围。规格中的键盘、焦点与辅助技术要求需要实际验收，不能由静态截图推断。
