# Artifactory 产品设计蓝图

## 产品主张

**把源码变成可信交付。**

用户描述想交付的应用，平台固定源码、生成可审阅计划、选择授权设备、完成多平台构建并呈现校验证据。正式发布冻结一次完整成功构建，团队能沿着任意制品追溯来源。

本蓝图面向完整产品想象。既有业务原则继续生效。跨项目聚合、计划比较、成本预测、策略检查和证据集合属于概念扩展，不代表当前服务端已实现。可交互原型使用本地演示状态，不发起真实构建、终端或发布。

## 界面层级与 Apple 准则

[Apple Liquid Glass](APPLE-LIQUID-GLASS.md)作为最高视觉准则。侧栏、导航与重要操作组成浮动功能层。项目、设备、构建证据与交付数据组成稳定内容层。

概览先呈现阻塞事项与交付事实。指标和趋势不使用液态折射。构建详情让阶段、日志和证据保持清晰，玻璃只用于导航与少量工具。设备页以身份、资源和恢复动作为重心，不用卡片倾斜暗示状态。

全局搜索独立于账户工具组。同类工具共享外壳，页面主动作保持唯一。弹出菜单从触发器位置展开。四步向导保留答案与焦点顺序，手机全屏任务使用更不透明的阅读底。

120 项组件按相同规则组合。展厅的标本边框用于分类，不能让每项标本变成玻璃卡片。媒体光学实验独立呈现，不能侵入业务内容。

## 1. 用户与权限

| 角色 | 目标 | 默认工作入口 | 关键操作 |
| --- | --- | --- | --- |
| 构建开发者 | 快速得到可用安装包与镜像 | 项目 → 版本 | 提交构建、读计划、看日志、下载制品 |
| 项目管理员 | 组织发布与项目访问 | 项目概览 | 创建版本、授权成员、配置默认签名、发布 |
| 工作空间管理员 | 保证设备、凭据与团队可用 | 工作空间项目目录 | 注册设备、配置节点池、签名与模型、邀请 |
| 工作空间所有者 | 决定组织生命周期 | 工作空间设置 | 所有权、归档、删除 |
| 系统管理员 | 维护平台入口与服务 | 平台设置 | 设备公开地址、平台运行配置 |
| 只读成员 | 查验交付与构建证据 | 版本详情 | 查看和下载授权对象 |

界面统一称「工作空间」。底层租户承担成员、项目与资源的隔离。工作空间所有者与管理员分别对应 owner 与 admin 权限。

实际动作受当前范围权限约束。界面读取前完成权限检查，不能通过前端隐藏替代服务端授权。不可执行动作显示原因；敏感配置在无权限时不读取正文。

## 2. 信息架构

```text
账户
├─ 登录 / 注册 / 邀请
├─ 工作空间大厅
├─ 通知中心（跨工作空间）
└─ 个人设置：资料 / 安全 / 偏好 / 通知

工作空间工作台
├─ 项目目录（选择空间后的默认入口）
├─ 概览
├─ 构建总览［概念扩展］
├─ 交付目录［概念扩展］
├─ 设备
├─ 节点池
└─ 管理工作空间
   ├─ 基本信息 / 成员与邀请
   ├─ AI 规划 / 签名 / Git 凭据 / 镜像仓库
   ├─ 访问令牌 / 审计 / 外部通知
   └─ 归档与删除

项目工作台
├─ 概览
└─ 版本列表
   └─ 版本详情
      ├─ 概览 / 构建记录 / 交付物
      ├─ 四步构建向导
      ├─ 构建详情：过程 / 执行 / 计划 / AI 审计 / 制品
      └─ 发布确认 → 已发布交付

管理项目（独立入口）
└─ 基本信息 / 成员 / 资源与凭据 / 签名 / Webhook / 生命周期
```

范围层级为账户 → 工作空间 → 项目 → 版本 → 构建。登录后先进入工作空间大厅。选择空间后直接打开该空间的项目目录。项目业务导航仅有概览与版本；管理项目独立呈现。构建属于版本，不另设项目一级导航。

原型用 hash 深链呈现可浏览屏幕。产品落地时使用工作空间、项目、版本与构建的可读层级路由。聚合页不改变对象归属。范围切换器与面包屑共同保留当前项目身份。

设置进入唯一分组侧栏，正文只保留当前表单。工作空间设置返回项目目录，项目设置返回项目概览。分区、版本目录和新建版本各有独立深链。命令面板只枚举当前工作空间与项目的导航样例，设计展厅收在独立原型工具组。

## 3. 核心用户旅程

### A. 第一次交付

登录 → 选择、创建或加入工作空间 → 项目目录 → 创建项目 → 连接只读仓库 → 检查设备与凭据 → 创建版本 → 发起构建 → 审阅计划 → 等待执行 → 检查制品 → 发布 → 下载与分发。

首次引导展示四个步骤：「连接项目」「准备构建资源」「创建版本」「发起构建」。已完成项显示证据链接。成员缺少资源授权时，指向管理员请求入口；不得自动扩大授权。

### B. 日常构建

项目概览查看完整窗口与近期活动 → 进入目标版本 → 选择源码与目标 → 确认构建 → 过程页查看当前动作 → 查看执行日志 → 下载候选制品。版本说明独立于构建要求。

### C. 构建失败与恢复

通知中心进入失败构建 → 过程页定位失败目标和阶段 → 执行页打开对应尝试 → AI 计划页查看依据与修订 → 回答待补充问题或重试 → 固定原源码继续尝试。

失败摘要使用「原因、影响、恢复动作」。原始日志与证据保持可展开。新建构建重新解析分支，原构建重试复用已固定清单，两种动作明确命名。

### D. 正式发布

版本详情 → 选择一次完整成功构建 → 展示源码、目标与摘要 → 核查全部任务已停止 → 确认不可变发布 → 固定交付清单 → 下载文件与 OCI 镜像。

发布失败只能重试相同冻结内容。不能换构建、覆盖版本或追加目标。稳定版与 RC 是两个独立版本。说明修正不改变交付身份。

### E. 设备恢复

工作空间概览看到资源阻塞 → 设备页定位离线宿主 → 详情查看最后采样与工具链 → 管理员恢复设备连接 → 排队任务继续执行。管理员手动发起 Emissary 升级；版本差异不触发自动执行。

### F. 团队协作

邀请成员 → 分配工作空间角色 → 授予项目与资源 → 成员接受邀请 → 关注项目 → 接收构建与发布事项 → 从通知深链回到业务对象。接受邀请不自动扩大项目或资源授权。

## 5. 主要页面布局

### 登录与注册

桌面左侧呈现品牌主张与玻璃交付雕塑，右侧为稳定表单。玻璃只用于主题工具与装饰；字段和说明不折射。登录与注册是独立页面。密码显隐不清空输入，允许密码管理器与粘贴。手机缩短叙事区，先完成账户任务。

认证使用用户名。注册用户名裁剪首尾空白，长度为 1–100 UTF-8 字节；密码为 12–256 UTF-8 字节，并须确认一致。实例关闭公开注册时不显示可提交的注册表单。当前契约不提供 SSO、找回密码和记住登录开关。

### 工作空间大厅

账户顶栏共用文档、通知和账户入口。主题进入账户偏好，支持跟随系统。首屏使用品牌主张和玻璃交付雕塑，随后呈现空间目录。卡片显示名称、角色和入口。搜索按名称或标识过滤。选择空间直接进入项目目录；创建空间只填写名称，也进入其空项目目录。生产标识由服务端生成。Northstar Studio 用于演示没有项目的空间。

大厅不推造最近访问时间、域名、项目总数或邀请数量。邀请链接独立确认工作空间与角色。项目权限由项目授权决定。设计与真实能力的剩余差异见 [同步矩阵](SYNCHRONIZATION.md)。

### 项目目录

顶部展示空间身份与唯一主动作「新建项目」。最近构建活动提供继续入口。目录共享一层玻璃搜索工具，支持状态筛选、名称排序、卡片与列表切换。关注仅在项目标题按项目独立保存。无结果保留条件并提供清除；空空间提供连接第一个项目。

空间项目数从该空间完整演示目录计算。列表、重点项目与项目切换器使用同一范围。空间之间不借用项目或构建快照。新建项目明确空间归属，创建后进入该项目概览。

### 工作空间概览

顶部为工作空间名称、日期窗口和一句状态摘要。首行四个指标，其次是构建趋势与「需要关注」，底部为活跃项目与设备可用性。待办优先展示失败、等待回答、证书到期和设备阻塞。概览统计读取授权范围完整窗口，不能从最近列表推算。

### 项目概览

标题旁保留关注星标，右侧主动作新建版本。项目设置使用独立次要入口。仓库来源位于标题下方。项目业务导航只有概览与版本目录。概览展示窗口内创建构建、成功率、成功周转中位数、当前进行中、逐日趋势与近期活动。版本目录支持SemVer排序和状态筛选；新建版本为独立页，保留多行说明与未保存保护。项目实体不定义当前版本。本地草稿按项目与版本保存，连续创建保留既有草稿。资源缺失通过有原因的待办呈现。

范围切换器显示项目与所属空间，仅列当前空间项目。「返回工作空间」回到项目目录。打开版本或构建时，面包屑继续显示所属项目。管理项目使用独立页面，不占用业务标签。

### 版本详情

版本号与不可变状态构成标题。概览、构建记录、交付物为页内标签。未发布时显示完整成功构建候选；已发布时展示来源构建与正式清单。版本说明有独立编辑入口。

### 构建详情

标题展示构建编号、版本、状态与来源摘要。构建包含过程、执行、计划、AI 审计和制品五个标签。过程视图呈现持久阶段。目标矩阵呈现并行平台，右侧摘要展示源码、计划和资源。执行页使用大面积稳定日志底色。计划页先显示可读结论，再显示命令。独立 AI 审计显示轮次、分片、工具参数和结果。

### 设备与节点池

概念版设备列表使用双列资源卡片。点击设备打开列表底页上的详情侧面板。深链可直接恢复侧面板。概览、资源、工具链、元数据和运维五个标签分层。终端使用独立页面，固定当前登录 owner，5 秒授权截止，45 秒租约回收。粘贴先确认内容，再明确发送。完整 ID 和原始元数据默认折叠。在线、排空与升级状态分别解释。

### 签名与凭据

原型使用固定无访问能力材料，允许预览字段、检查失败、保存公开元数据、停用版本和设置默认方案。真实密钥、证书与私钥不进入原型存储。

列表优先显示证书用途、身份、有效期、方案与授权范围。导入步骤明确材料类型和用途。私钥不提供查看或导出。构建快照固定凭据版本，轮换不改变历史构建。

## 6. 对象状态与动作

| 对象 | 状态 | 允许动作 | 解释要求 |
| --- | --- | --- | --- |
| Release | 草稿 | 编辑说明、发起构建、选择完整构建 | 版本号不可修改 |
| Release | 发布中 | 查看冻结清单 | 禁止新建与重试构建 |
| Release | 发布失败 | 重试相同冻结内容、编辑说明 | 保留绑定摘要 |
| Release | 已发布 | 下载、编辑说明、分发选中镜像 | 不覆盖、不追加、不换构建 |
| Build | 源码准备 | 查看解析记录、取消 | 展示所选 ref 与固定 OID |
| Build | AI 规划 | 阅读计划、回答问题、取消 | 展示预算与当前版本 |
| Build | 排队 | 查看目标与等待原因、取消 | 离线设备保留排队 |
| Build | 执行中 | 看日志、看尝试、取消 | 目标独立执行 |
| Build | 成功 | 下载候选、参与发布选择 | 成功不等于正式发布 |
| Build | 失败 / 失联 | 查看原因、允许时重试 | 重试复用固定源码 |
| Device | 在线 | 执行授权任务、查看采样 | 展示槽位与能力 |
| Device | 离线 | 查看最后快照、等待恢复 | 不把旧采样当实时 |
| Device | 升级 | 查看管理员发起的进度 | 不自动因版本差异执行 |
| Tenant / Project | 归档 | 只读、下载、允许时恢复 | 新任务禁止进入 |

## 7. 全局状态规范

| 状态 | 页面行为 | 恢复动作 |
| --- | --- | --- |
| 首次加载 | 匹配内容骨架；无可点击占位 | 失败后停止骨架并提供重试 |
| 后台刷新 | 保留内容、标签和草稿 | 失败只提示数据更新时间 |
| 无数据 | 明确当前对象为空 | 创建对象或阅读说明 |
| 筛选无结果 | 保留筛选与输入 | 清除某项或全部筛选 |
| 无权限 | 移除敏感正文，解释所需角色 | 返回授权范围或联系管理员 |
| 对象不存在 | 保留上级上下文 | 返回列表 |
| 会话过期 | 保留可安全恢复的本地草稿 | 登录后回到原对象 |
| 网络断开 | 保留最后读取内容并标记时间 | 重试或重新连接 |
| 请求冲突 | 保留输入，解释对象已变化 | 重新读取并比较 |
| 不可逆动作 | 显示对象、范围和不可逆边界 | 取消或显式确认 |

## 8. 概念扩展

| 概念 | 用户价值 | 设计边界 |
| --- | --- | --- |
| 交付证据集合 | 一处查看源码、计划、签名和摘要 | 只汇集已存在证据；缺失标明缺失 |
| 构建比较 | 对照两次构建的来源、要求、目标与耗时 | 不把不同源码称为可复现验证 |
| AI 排错建议 | 从失败证据得到可审阅修订 | 用户确认后创建新计划版本 |
| 资源等待预测 | 帮助选择时间与平台 | 标注估算依据，未知不填百分比 |
| 跨项目构建与制品目录 | 快速定位近期工作与交付 | 保留工作空间与项目权限过滤 |
| 策略检查 | 发布前集中显示可用证据与缺口 | 不把建议误称签名、安全或合规认证 |
| 发布说明草稿 | 从已选构建生成可编辑说明 | 用户确认，说明与执行要求分离 |

原型可以展示未来能力，但界面中的业务动作不执行真实服务端变更。正式开发前分别定义契约、权限和数据来源。

## 10. 成功指标与交付边界

产品研究关注首次成功交付时间、构建失败到定位原因的时间、发布确认错误率和无效资源请求次数。研究样本与真实服务端数据独立记录，不能以原型演示数字作为指标结论。

设计交付包含全局规范、组件规格、产品蓝图、机器可读 tokens 与可浏览原型。原型交互不代表数据库、权限、安全、签名和硬件链路已完成验收。原型验证只对实际执行的页面、交互与视口作出结论。
