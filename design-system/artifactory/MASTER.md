# Artifactory · Prism / 流光工作台

版本 1.4 · 2026-11-27 · Web 优先，兼顾平板与手机。

Prism 把源码、计划、设备和交付串成可读路径。稳定底色承载内容，液态玻璃承载导航与重要操作。墨色文字承载事实，钴蓝标记下一步动作。

[Apple Liquid Glass 最高准则](APPLE-LIQUID-GLASS.md)约束本文与所有组件分册。Apple 官方原则优先于早期 Prism 材质方案。第三方研究仅补充光学实验。

此规范定义控制台与独立原型的共同设计语言。[控制台规范](../../docs/design-system.md)记录真实交互合同。原型中的业务数字和状态均为演示数据。概念扩展必须明确标记，不能反向成为生产 API、权限或数据能力。

## 1. 设计原则

1. **交付有出处**：每份制品能追溯版本、构建、源码与签名。
2. **状态能解释**：同时显示当前状态、形成原因和下一步操作。
3. **一屏一个重心**：每页一个主动作。复杂信息逐级展开。
4. **材质有层级**：玻璃形成独立功能层；卡片、图表、表格和日志采用标准内容表面。
5. **操作有回声**：按下立即反馈，结果通过顶部居中通知确认。
6. **视图能延续**：筛选、草稿、滚动和阅读位置随上下文保留。

## 2. 品牌表达

产品名称统一使用 **Artifactory**。Prism 是设计语言名称。沿用现有「装配 A」品牌资产，保留横梁切口与比例。浅色使用现有深色符号，深色使用反白符号。彩虹只出现在玻璃边缘和展示性光场，不能替代品牌符号。

| 元素 | 规定 |
| --- | --- |
| 关键词 | 清澈、精确、通透、从容 |
| 品牌主色 | Cobalt / 钴蓝；用于主要操作与当前位置 |
| 环境色 | Mist Blue、Apricot、Lilac；只作低饱和静态背景 |
| 文字语气 | 动词开头；明确对象；直接说明结果 |
| 图标 | 统一线性 SVG，20px，1.75px 笔画；使用现有 Lucide 家族 |
| 插画 | 透明棱镜、堆叠制品、节点连接；只用于认证、空态和展示 |

禁止 emoji 导航、彩色操作按钮混用、为每个数据指标添加装饰图标。禁止更改官方平台 Logo 的比例与配色。

状态优先级：失败 / 需操作 → 执行中 → 排队 → 成功 → 中性。一个对象只出现一个主状态，签名与发布分别呈现独立状态。

## 4. 液态玻璃材质

Liquid Glass 形成浮于内容之上的功能层。侧栏、导航、重要工具组和临时浮层采用该材质。指标、项目、设备、图表、表格、日志及组件标本外框采用 Standard 内容表面。禁止把每张卡片变成独立透镜。

### 材质分层

| 层 | 名称 | 设计 |
| --- | --- | --- |
| 0 | Canvas | 低强度静态环境色，不持续漂移 |
| 1 | Standard | 稳定珠光底色，按分组留白和分隔线组织 |
| 2 | Regular Glass | 导航、重要工具组与文字浮层；调节透明度以保持阅读 |
| 3 | Clear Glass | 只用于媒体上方的少量控件与光学实验 |
| 4 | Prominent | 页面唯一主要动作，强调色背景 |

Regular 是业务默认玻璃变体。Clear 不是阅读面板的名称。明亮媒体下的 Clear 控件按需增加 35% 黑色遮罩，并检查合成对比。长表单与全高 sheet 增加不透明度。

同类工具共享一层材质。组内按钮保留命中区和焦点，不重复背景模糊。内容卡片内只使用 Standard 次分组。工具使用中性色，主要动作和语义状态才使用强调色。

### Prism 的 Web 参数

以下数值延续指定风格，不是 Apple 固定参数。它们只约束适合的 Regular Glass 外壳。

| 参数 | 项目值 | 使用范围 |
| --- | --- | --- |
| 背景滤镜 | `blur(10px) saturate(210%)` | Regular Glass 外壳 |
| 外圆角 | `30px` | 大型导航或浮层；小控件按尺寸调整 |
| 色散边 | `1px` | 外缘，保持细弱 |
| 内高光 | `inset 0 1px 1px rgba(255,255,255,.95)` | 浅色玻璃；深色减至 `.26` |
| 深柔影 | `0 20px 52px -28px rgba(34,57,102,.30)` | 浮动功能层 |
| 近接触影 | `0 6px 16px -10px rgba(34,57,102,.16)` | 浮动功能层 |
| 浅色玻璃 | `.72` 白色顶面 → `.44` 淡蓝底面 | 导航与工具外壳 |
| 深色玻璃 | `.82` 蓝灰顶面 → `.64` 深蓝底面 | 控制台导航与工具外壳；文字浮层提高不透明度 |
| 顶部弧 | 容器宽度 72%，高度 18px；顶部对齐 | 大型玻璃外壳，限制溢出 |
| 色散渐变 | 蓝 → 紫 → 粉 → 杏 → 青 | 低强度细边，不能染色正文 |

背景复杂时提高表面不透明度。不能只提高模糊强度弥补对比不足。固定导航在滚动边缘使用柔和渐隐，防止内容与控件争夺注意力。

独立原型的 Regular 外壳使用更高不透明度：浅色 `.86` → `.76`，深色 `.92` → `.86`。菜单、模态与内容相交处继续提高实体比例。参数差异用于保持合成后的清晰度，不改变 Standard 与 Regular 的职责。

### 交互光学层

Standard 可使用不透明珠光渐变、顶部内光和柔阴影。
这些层次不读取背景，也不进行折射。

局部反光只作用于导航、重要控件与实验透镜。它只在精细指针悬停期间更新，离开后停止。内容卡片、设备图标和标本外框不追踪反光或倾斜。

指针进入功能外壳时，斜向流光掠过一次。
固定裁切层约束内层光带，不截断菜单和焦点。
指针在同一外壳内移动时不重播流光。
导航、标签和顶部工具使用临时悬停胶囊。
胶囊在同组控件间连续移动，不改变选中语义。
悬停胶囊不重复背景模糊，文字保持原形。

主导航和标签导航通过移动选中形状维持空间连续性。文字与图标保持原形，并保留 `aria-current` 或选中语义。菜单与浮层从触发位置连续展开，不能用折射扭曲正文。

滑块与开关的活动部件在按下或拖动时强化玻璃质感。触摸使用按下反馈，键盘使用清晰焦点。光学装饰不截获事件，不改变命中区。

不支持 backdrop-filter、减少透明度或强制颜色时，改用实体 `surface`。减少动态效果独立关闭运动，不强制改变主题与透明度。

## 5. 字体与排版

界面使用本地 Inter Variable。中文依次回退到 PingFang SC、Microsoft YaHei、系统无衬线字体。日志、命令、版本、哈希和耗时使用 IBM Plex Mono。字体 `font-display: swap`，不请求外部字体服务。

| 角色 | 字号 / 行高 | 字重 | 使用位置 |
| --- | --- | --- | --- |
| Display | 44–64px / 1.22 | 600–630 | 认证品牌、首次欢迎、产品展示 |
| Page / H1 | 32 / 40px；手机28px | 600 | 页面主标题 |
| Section / H2 | 24 / 32px | 600 | 大分区标题 |
| Card / H3 | 18 / 26px | 600 | 面板标题、弹层小标题 |
| Body | 16 / 26px | 400 | 长说明、阅读正文与手机输入 |
| Compact | 14 / 22px | 400–500 | 桌面表格、导航、控件标签 |
| Caption | 12 / 18px | 400–500 | 时间、辅助说明 |
| Metric | 32 / 40px | 600 | 主要统计；tabular-nums |
| Code | 13 / 22px | 400 | 日志、命令；手机可横向局部滚动 |

英文大标题字距 `-.025em`，中文和正文按场景控制字距。英文分组标签 11px / 16px、字距 `.08em`，需附可见业务标题。长文宽度控制在 65–75 个英文字符。手机输入保持至少 16px，元数据与辅助说明按 Caption 呈现。金额、版本和计时器使用等宽数字。

标题按 H1 → H2 → H3 顺序。长名称优先换行；列表截断必须提供可聚焦的完整内容。哈希可简写前 8 位，并提供复制完整值。URL 使用 `overflow-wrap: anywhere`。

## 6. 空间、圆角与层级

| 维度 | 值 |
| --- | --- |
| 间距 | 4、8、12、16、20、24、32、40、48、64px |
| 控件内部 | 左右 16px，图标与文字 8px |
| 相关字段 | 16px；字段组之间 32px |
| 面板内边距 | 常规 24px；宽屏 32px；手机 20px |
| 页面分区 | 32px；标题与正文 24px |
| 圆角 | 小标签 8px、输入 12px、浮层 20px、内容 24px、主玻璃 30px、按钮胶囊 999px |
| 控件高度 | 默认按钮36px、紧凑32px；输入44px；筛选40px；触摸不低于44px |
| 图标 | 16、20、24、32px；同一层级统一大小 |
| 层级 | 背景 < 内容 < 粘性导航 < 菜单 < 遮罩与模态 < notify；嵌套模态逐层提升 |

嵌套容器使用同心圆角。内半径按外半径减去内间距计算，并设合理下限。工具组外壳、选中形状与命中区共同校准。不能把 30px 套用到所有组件。

认证页输入与提交高 52px，表单输入圆角 14px。组件展厅的专属尺寸见第14节，不覆盖真实控制台的共享默认值。

## 7. 布局系统

桌面采用浮动侧栏和内容画布。侧栏宽 236px，距视口边缘 16px。内容起点为 268px。顶栏最小高度 64px，顶部间距 16px，主内容最大宽度 1600px。页面标题左对齐，主动作位于右侧。面包屑只表达层级。

页面按任务选择网格，常规间距24px。概览指标宽屏四列，窄内容区两列；两个图表等宽，内容小于780px时纵向排列。项目与设备目录宽屏使用两列 Standard 卡片。版本和构建详情保留可见上下文返回入口。宽编辑模态与设备侧面板分别保持自身阅读宽度，不以统一栅格强制拉伸。

| 宽度 | 导航 | 内容行为 |
| --- | --- | --- |
| ≥1440px | 236px 浮动侧栏 | 宽画布；最多四个指标并排 |
| 1024–1439px | 236px 侧栏 | 按内容宽度收拢图表与目录 |
| 768–1023px | 菜单按钮打开抽屉 | 两列卡片；核心操作保持可见 |
| 375–767px | 顶栏菜单抽屉 | 单列；16px 页面边距；宽表与单行筛选局部滚动 |

手机不增加第二套同级导航。表格优先改为具名记录卡片；原始宽表只在自身容器滚动。横屏与 200% 缩放保留内容和操作。粘性操作区预留正文空间并避开 safe-area。

## 8. 导航与交互

工作范围依次是账户、工作空间、项目、版本、构建。界面统一称「工作空间」，底层对应租户隔离边界。登录后先选择工作空间，再直接进入该空间的项目目录。

范围切换器只选择工作范围。工作空间提供概览、项目、节点池、共享设备和空间管理。节点池表示原生设备的授权与调度范围，独立 BuildKit 镜像构建池不混入该目录。项目业务导航仅保留「项目概览」「版本」。「管理项目」是独立管理入口。构建从版本进入；跨项目构建与制品聚合属于概念扩展。

进入项目后，范围切换器显示项目与所属工作空间。项目切换列表只展示当前空间的项目。「返回工作空间」回到项目目录。面包屑按工作空间、项目、版本、构建递进。版本和构建页面保留所属项目身份，导航选中「版本」。

登录使用品牌叙事与实体表单双区布局，手机收拢装饰，保留清晰表单。真实登录使用用户名；注册遵循实例开关、确认密码和12–256 UTF-8字节密码合同。没有 SSO、找回密码或记住登录的真实接口时，不呈现这些操作。工作空间大厅突出授权目录、搜索和创建入口；邀请通过独立链接进入。项目目录提供搜索、状态筛选、排序、卡片与列表切换。空空间不借用其他空间的数据。

入口雕塑是独立装饰层，不能成为可点击业务对象。功能玻璃承载主题、账户、搜索与筛选。表单、空间身份和项目数据使用 Standard 阅读底。入场与反光响应当前操作，空闲时保持静止。

全局顶栏提供当前位置、搜索、文档与通知。桌面账户位于侧栏底部，窄屏位于通知右侧。语言与主题在认证工具和个人偏好中调整。页面动作留在标题区域。当前导航使用胶囊、钴蓝图标和文字权重共同表达；每个任务区保留明确主动作。

生产设备详情使用「概览 / 资源 / 工具链 / 元数据 / 运维」五标签。终端为独立页面，保留原登录Session、授权能力与租约回收。设备未知值不推作零，列表不逐卡请求遥测。终端材质只改变外围工具，不覆盖xterm背景、输入与滚动。

`⌘/Ctrl K` 打开命令面板，搜索当前范围的导航与授权设置，并提供可访问项目切换。它不承诺尚不存在的版本与构建全文搜索。方向键移动，Enter 确认，Esc 关闭。不能覆盖终端输入、浏览器与辅助技术保留快捷键。

所有关键页面有深链。浏览器返回恢复筛选和滚动。切换工作空间取消旧范围请求，清除旧范围搜索与项目选择。轮询不重置标签、草稿、日志滚动和展开状态。范围外对象显示不可用状态，并提供返回当前项目目录的入口。

真实入口使用 `/tenants/:slug/projects`。大厅选择、创建完成与切换工作空间进入该目录。项目、版本、构建和终端深链保留工作空间范围。构建详情固定为「过程 / 执行 / 计划 / AI审计 / 制品」五标签，首次统一进入过程，后续刷新保留用户选择。

## 9. 反馈与状态

首次读取使用匹配实际结构的骨架，区别于空数据。前台读取与导航共用顶部 2px 进度线，延迟 150ms 显示。后台轮询和日志订阅保持静默。未知进度不显示虚构百分比。

操作结果使用顶部居中 notify，不占布局、不抢焦点。当前控制台普通结果停留5秒，错误停留10秒；悬停或聚焦暂停计时。错误保留可读说明与关闭入口。原生字段校验仍阻止提交，统一通知说明并聚焦首个无效字段。业务失败保留草稿与重试入口，不为装饰新增错误摘要或字段跳转能力。

空态由「对象 + 原因 + 下一步」组成，例如「还没有版本。创建版本后即可发起首次构建」。权限不足说明所需角色并提供返回。网络失败保留已有内容和草稿，提供重试。离线快照标记采样时间。

## 10. 动效

组件展厅包含 120 项标本和 12 个分类。目录、三份组件分册与产品核心模式共享本规范。外部液态玻璃研究见 [LIQUID-GLASS-REFERENCE.md](LIQUID-GLASS-REFERENCE.md)。

方向镜面亮边只用于重要功能层和光学实验。指针角度控制反光位置，遮罩将反光限定在细边。实验将折射、着色、镜面与文字分层。10/16/26px 棱镜宽与 38/62/100 虚拟厚度只属于实验预设。正文、内容卡片与日志不进行位移折射。

| 事件 | 时长 | 曲线 / 行为 |
| --- | --- | --- |
| 共享按下反馈 | 120ms | 控制台按钮轻压至`.97`；键盘保留焦点 |
| 共享状态过渡 | 200ms | 颜色、背景和阴影衔接最终状态 |
| 控制台模态入场 | 280ms | `cubic-bezier(.22,.8,.25,1)`；轻移与透明度 |
| 控制台悬停胶囊 | 150–220ms | 同组移动与离开淡出，不改变选择语义 |
| 控制台外壳流光 | 650ms | 进入时单次掠光，组内移动不重播 |
| 认证和大厅入场 | 650–900ms | 只装配首屏装饰层，完成后静止 |
| 原型菜单、形变与主题光环 | 180–780ms | 当前事件触发，可中断；主题先写入最终值 |
| 原型图表首次出现 | 600–860ms | 首次进入视口绘入；不循环，不改变比例 |
| 生产数据图表 | 立即呈现 | 保留零值、断点和真实时间窗，不反复绘入 |

单屏以当前操作作为运动重心。环境光保持静态；高光只响应当前操作。禁止持续漂移、持续闪烁、磁吸光标和大范围视差。页面空闲时不保持装饰动画循环。

原型导航可用 FLIP 衔接形状，控制台悬停胶囊在当前组内连续移动。两者均保留当前选择和清晰焦点。导航与弹层优先动画 transform 和 opacity，布局先写入最终值。内容卡片不作倾斜。原型图表按需首次绘入，生产实时图表直接显示真实数据。数字立即显示最终值，不通过计数动画虚构变化。

模态轻移进入，关闭立即恢复页面语义与焦点。原型允许无交互装饰快照退场。向导切换只过渡内容层，保留已填答案。动效不能阻止输入、关闭、返回或焦点恢复。

快速重复操作取消旧动画并写入最新状态。清理被取消的动画与装饰节点。业务状态不依赖 animationend 或 transitionend。页面隐藏、组件移除和范围切换后停止追踪。

主题立即写入最终状态，原型装饰高光环单次扩散。
高光环不复制页面，也不拦截点击。
快速切换取消旧光环，以最新主题意图为准。
不支持动画或启用辅助材质偏好时直接更新主题。

`prefers-reduced-motion: reduce` 下关闭位移、缩放、倾斜、涟漪、描线与错峰，直接呈现最终状态。`data-transparency=reduce`、系统减少透明度与 forced-colors 下关闭反光、折射、色散与背景滤镜，使用实体底和清晰边界。

## 11. 图表与数据

本节定义共同图表语言。组件库示例的专项调整不自动改动产品原型；每个界面须独立验证真实比例。产品数据复核见 PRODUCT-REVIEW.md。图表使用 Standard 内容表面。玻璃只承载浮动筛选和工具。数据不加折射、光晕或动态背景。

| 图形 | 形态与渐变 | 数值与边界 |
| --- | --- | --- |
| 折线 / 微图 | `monotoneX`或保形三次曲线；主线2.5–3px，微图2.4px；圆线端、圆连接与同色渐变 | 穿过采样点；不越过相邻极值；缺失采样断开；孤立点可见 |
| 面积 | 同色透明度 20% → 3% → 0 | 仅辅助趋势；不能代替主线 |
| 柱状 | 上下相同圆角；顶部浅色到底部深色 | 零基线；圆角不大于半宽与半高；不增加小值高度 |
| 环形占比 | SVG 圆端弧；同色渐变；小分段收窄为短胶囊 | 分段角度按真实比例；圆帽包含在角度内，避免扩大比例 |
| 单环进度 | SVG 圆线端，12px 轨道 | 中心显示百分比；0% 隐藏前景；100% 连续闭环 |
| 容量仪表 | 180° 圆端弧，16px 轨道；连续渐变 | 中心显示使用量 / 上限；两端标注 0 与上限 |

主系列使用钴蓝，失败使用玫瑰色，中性使用蓝灰，资源内存使用紫色。明暗主题各有色阶。主要线条与背景对比不低于 3:1。文字、图例与数值共同表达状态。

生产图表通过语义变量选择系列颜色，内存趋势复用成功色。堆叠柱分段保持实际高度，微小比例也使用相同上下圆角。容量条精确设置比例宽度，禁止以最小宽度放大小值；0%不绘前景。

图表标注时间范围和单位。精确数值通过文字摘要或可展开数据表提供。无样本显示空态。占比限制为少量分组；平台数量比较优先使用柱状图。

原型更新动画为650ms，使用 `cubic-bezier(.22,.75,.2,1)`。语义数值先提交，后续操作可中断动画。首次柱体绘入600ms，弧段淡入700ms，折线描绘800ms，只在进入视口时绘入一次。生产概览与设备趋势关闭绘图动画，后台刷新不重复演出。禁止循环扫光与数字滚动；减少动态效果时立即呈现最终图形。

## 12. 可访问性与性能门槛

目标为 WCAG 2.2 AA。正文和辅助文字对比至少 4.5:1，大字至少 3:1，交互边界与焦点至少 3:1。已按 sRGB 相对亮度公式核算本页实体语义色：浅色正文、次文字、辅助文字与 surface 分别为 15.53、6.18、5.09:1，主按钮为 5.87:1；深色对应为 14.51、8.65、7.01:1，主按钮为 8.25:1。四种状态色对各自底色均超过 5.6:1。透明材质必须在最亮与最暗背景位置测量最终合成色。实体基准核算不等于已完成浏览器测量。

每个图标按钮提供名称。装饰 SVG 使用 `aria-hidden`。字段使用可见 label。模态限制焦点，关闭后返回触发器，Esc 关闭最上层浮层。粘性顶栏不能遮挡焦点。提供跳到主内容链接。

所有拖动提供按钮或键盘替代。触摸目标至少 44×44 CSS px。Web 最低 24px 标准不能替代本产品的 44px 舒适目标。页面支持 200% 缩放、减少动态效果、减少透明度与 forced-colors。

只为主材质使用背景模糊。真实长列表按现有分页或按需读取合同加载；需要虚拟化时先验证焦点、语义和定位。原型演示列表保持自然 DOM。预留图表与骨架尺寸。只预载主要字体。不引入运行时外部字体、自动播放媒体和常驻背景动画。
