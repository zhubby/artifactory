# 输入与操作组件 · 40 项

组件演示只改变当前页面状态。输入不发送至服务端。所有弹出选择使用自定义触发器。[Apple 最高设计准则](APPLE-LIQUID-GLASS.md)约束材质。输入正文使用 Standard；导航与重要工具组使用 Regular Glass。标本外框不加液态材质。

## 操作与快捷

### A01 按钮 Button
- 高度至少 44px；999px 胶囊；13px 字号。主动作图标 16px。主动作使用 Prominent；普通操作使用 Regular；危险与禁用使用实体面。
- 点击显示结果。执行中禁止重复触发。禁用态不触发涟漪。
- Tab 聚焦；Enter 与 Space 激活。每组只保留一个主操作。

### A02 图标按钮 Icon button
- 48×48px 圆形 Regular 工具；图标 20px。名称通过 aria-label 提供。选中使用主色浅底、描边和图标浅填充。
- 关注和订阅使用 aria-pressed。下载使用一次性结果反馈。
- 焦点轮廓不被玻璃边缘裁剪。陌生图标需要文字说明。

### A03 分裂按钮 Split button
- 4px 内衬的 Regular 胶囊外壳。主按钮与 44px 菜单触发器共用分隔线。内角只保留两端弧线，不重复模糊。
- 默认动作独立执行。备选动作在自定义菜单中选择。
- Enter 展开；Tab 遍历；上下键在菜单内移动；Escape 关闭并回焦点。

### A04 按钮组 Button group
- Regular 共享胶囊使用 5px 内衬、4px 项间距。内部按钮至少 40px 高、64px 宽，文字 13px，长标签自然换行。
- 切换只保留一个 aria-pressed=true。选中胶囊使用实体底、细边与局部柔影。
- Tab 与 Enter 完成切换。按钮组用于同层操作，不替代页面导航。

### A05 切换按钮 Toggle button
- 高度至少 44px；Regular 胶囊；13px 字号。切换后保留 17px 心形图标，文字与按下态同步更新。
- 当前值使用 aria-pressed。开启与关闭都有可读反馈。
- Space 与 Enter 均可操作。动作名使用「关注项目」等直接动词。

### A06 文本链接 Link
- Standard 正文链接使用 14px 字号、14px 图标。列表间距 18px。悬停与焦点显示下划线。
- 外部目的地使用外链符号。原型点击保留位置并说明结果。
- Enter 激活。链接只用于导航，数据修改使用按钮。

### A07 浮动操作 Floating action
- 58px 圆形 Regular 主动作；图标 24px。工作空间内容使用 24px 实体容器与 22px 内衬，数量使用 30px 字号。
- 单一新增动作更新可见对象数，不遮挡其他控件。
- Tab、Enter 和 Space 可操作。工作台最多使用一个浮动主动作。

### A08 复制按钮 Copy button
- 22px 实体摘要容器。11px 标签与 12px 等宽摘要分层。44px 圆形复制工具紧邻文本，正文允许长词折行。
- 复制成功显示文字；剪贴板不可用时提供可读原始值。
- 按钮名称包含所复制对象。成功后保留焦点和正文。

### A09 加载按钮 Loading button
- 至少 44px 高的 Regular 胶囊保持稳定。检查期间显示「正在检查」。
- 执行期间 disabled。完成后恢复按钮并显示本地演示结果。
- 导航离开时清理定时器。结果不自动发起下一步。

### A10 快捷键 Keyboard shortcut
- 22px Standard 容器与 16px 内衬。键帽至少 31×30px、8px 圆角、12px 等宽字。说明独立一行，手机操作按钮独占一行。
- 聚焦示例区域后 Alt+B 执行。退出区域后不注册全局组合键。
- 不占用系统常用组合。键盘与按钮路径使用同一结果反馈。

## 文本与表单

### F01 文本输入 Input
- Standard 输入至少 46px 高、15px 圆角、12×14px 内衬。桌面正文 14px、手机 16px；上方标签 13px，间距 9px。
- 只读输入使用实体浅底与虚线边界。聚焦输入显示主色边与 3px 浅色外圈。提示不替代标签。
- 支持键盘选择、粘贴与撤销。对象标识只读，显示名称可编辑。

### F02 多行输入 Textarea
- Standard 正文初始 3 行；14px 常规字重、1.5 行高、15px 圆角。允许垂直调整高度。12px 计数在下方右对齐。
- 240 字上限，计数随输入更新。正文区域不使用折射形变。
- Enter 换行。保存使用独立按钮，不能把普通 Enter 当提交。

### F03 密码输入 Password input
- Standard 输入与显隐工具共用 16px 实体外壳。内部 38×38px 圆形显隐按钮无独立边框。名称随状态更新。
- 切换 type 保留内容。说明明确要求使用虚构演示内容。
- 显隐不改变表单顺序。产品实现必须允许密码管理器与粘贴。

### F04 步进数字 Number input
- Standard 共享胶囊使用 5px 内衬、6px 间距。两侧按钮 42×42px；中间为 22px 等宽数字，输入高度 42px。
- 演示范围 1–16。边界外点击保持边界值，并展示当前数。
- 输入支持上下键。需要精确数值时保留直接输入路径。

### F05 即时搜索 Search input
- Standard 输入与结果列表间距 12px。列表 18px 圆角；结果行至少 44px 高、13px 字号，7px 标记辅助定位。
- 输入即时筛选；无匹配显示明确空结果。清空后恢复全部结果。
- 使用 search 输入语义。过滤不改变当前焦点与查询文本。

### F06 验证码输入 OTP input
- 六个 Standard 等宽单元，至少 56px 高、14px 圆角、23px 等宽字。手机至少 48px 高、11px 圆角、20px 字。
- 数字输入后前进；空位退格向前。粘贴一次填充六位。
- 每格命名「第 N 位验证码」。填满时只报告结果，不自动提交。

### F07 单位输入 Unit input
- 46px Standard 数字字段与 Regular 单位触发器底部对齐，间距 8px。单位触发器至少 85px 宽，数字区域优先伸展。
- 单位使用自定义菜单。选择后写回触发器并关闭菜单。
- Tab 独立访问数字和单位。不能只用占位符说明单位。

### F08 字段验证 Field validation
- Standard 字段显示错误边框与 3px 低强度错误外圈。12px 修正文字位于下方，通过 aria-describedby 关联。
- 离开字段后验证 SemVer。修正后清除 aria-invalid 并显示有效状态。
- 错误不清空用户输入。提交验证应定位首个错误字段。

### F09 行内编辑 Inline edit
- 20px Standard 外壳使用 6px 内衬。阅读态正文无框；编辑态恢复字段边界。按钮至少 40px 高，在「编辑／保存」间切换。
- 编辑后聚焦并选择文本。保存恢复只读态和结果说明。
- 不依赖双击进入。关键标识和正式版本号禁止行内修改。

### F10 代码输入 Code input
- Standard 配置面使用 12px 等宽字、1.9 行高、18px 圆角与 16px 内衬。保持垂直调整能力，下方独立验证按钮。
- 每行使用 KEY=value。格式验证说明有效行数或具体修正方式。
- Enter 插入换行。示例配置不包含真实凭据或可执行命令。

## 选择与调节

### S01 复选框 Checkbox
- 20px 原生语义复选框，视觉圆角 6px。Standard 选项行至少 44px 高、14px 圆角。选择同时显示勾号与浅色面。
- 多个独立选项可同时选择。组织锁定项同时展示勾选与禁用状态。
- Space 切换。字段组使用 fieldset 与 legend。

### S02 单选组 Radio group
- 20px 圆形原生语义单选，中心点 8px。Standard 标签行至少 44px 高。选中具有浅色整行背景，选项拥有相同 name。
- 同组仅一个选中。完整策略名称保留在标签中。
- 原生方向键切换、Space 选择。互斥策略不使用复选框。

### S03 开关 Switch
- 52×32px 轨道与 24px 圆形滑块。22px Standard 设置面内分列标题与说明，字号分别为 14/12px。按下滑块呈现局部玻璃，点击整行可切换。
- role=switch 与 checked 共同表达状态。结果即时显示。
- Space 切换，焦点显示在轨道外。延迟保存的配置使用复选框。

### S04 单选下拉 Select
- Regular 触发器至少 44px 高，999px 胶囊。Regular 菜单外圆角 24px，内部选项至少 42px 高、15px 圆角。箭头随展开旋转。
- 选项点击写回触发器，关闭并恢复触发器焦点。
- Tab、Enter、上下键和 Escape 可操作。禁止原生 select 菜单。

### S05 可搜索建议 Combobox
- Standard 输入下方显示 Regular 候选列表。列表经共享光学层统一为 24px 圆角，保留 6px 内衬。候选至少 43px 高、13px 圆角，选中有勾号。
- 输入筛选构建池；选择写回输入并更新选中语义。
- 下键进入候选；上下键及 Home/End 移动。Enter 选择，Escape 关闭并回焦点。

### S06 多选下拉 Multi select
- 44px Regular 胶囊显示已选数量。24px Regular 菜单中使用 44px 标签行与 20px 复选框，选中同时显示勾号与背景。
- 每次选择更新数量并保留菜单，支持连续选择。
- Space 勾选，Escape 关闭。数量不能替代已选名称的可读路径。

### S07 标签输入 Tag input
- 20px Standard 编辑面包含胶囊标签。标签文字 12px，删除目标 28px 圆形。内部输入无重复边框，集合先换行，长词允许折行。
- Enter 创建；重复标签显示解释。删除按钮以完整标签命名。
- 输入框一直可访问。不能用颜色作为唯一分类信息。

### S08 滑块 Slider
- Standard 轨道为 8px 圆端胶囊；Chromium 拇指 28px，Firefox 为 26px 加边框。激活拇指呈现局部玻璃；18px 等宽数值即时显示。
- 示例范围 10–100%。轨道两端显示边界。
- 左右键微调，Home 与 End 到边界。精确业务参数另提供数值输入。

### S09 区间滑块 Range slider
- 两个 8px 圆端轨道分别命名。17px 等宽区间摘要展示数值，端点标签 12px。拇指与单滑块保持同一尺寸。
- 调整任一端时保持开始不晚于结束。演示值为 0–23 小时。
- 两个滑块分别接收焦点。禁止两个无名称重叠手柄。

### S10 颜色选择 Color picker
- Standard 色样 42px 圆形，间距 14px。选中显示勾号与 2px 轮廓，轮廓外偏移 4px。
- 每种颜色有可读名称；aria-pressed 随选择更新。
- Enter 与 Space 选择。颜色不承担状态或权限的唯一表达。

## 日期与文件

### D01 日期选择 Date picker
- 280px 七列月历位于 30px Regular 弹层。手机月历 246px 宽。月份标题 14px，日期 12px 等宽字，选中与翻页工具为圆形。
- 点击日期更新 YYYY-MM-DD 摘要。当前选择使用实色与 pressed 状态。
- 每日独立按钮命名完整日期。Escape 返回触发器。

### D02 日期区间 Date range
- 与日期选择共享 280px 月历和 30px Regular 弹层。胶囊触发器显示完整起止日期，选择说明另起一行。
- 首次选开始、再次选结束；反向选择自动按日期排序。
- 新一次选择重置旧区间。关闭后保留完整区间摘要。

### D03 时间选择 Time picker
- Regular 菜单中小时和分钟分列。列高最多 230px，独立滚动。时间为 15px 等宽字、38px 高胶囊，列标题固定显示。
- 示例小时 09–18、分钟 00/15/30/45。当前值更新为 HH:mm。
- 按钮显示 pressed 状态。Tab 与 Enter 选择，不只支持滚轮。

### D04 日历 Calendar
- 内嵌 Standard 月历填充可用宽度，最大 310px。24px 外圆角与 16px 内衬。圆形日期单元，周一至周日始终可见。
- 前后月根据真实月份天数重绘。当前日期选择与计划结果分开表达。
- 完整日期通过 accessible name 提供。日历不代表服务端任务已排程。

### D05 文件上传 File upload
- Standard 区域至少 186px 高、24px 圆角。54px 徽记使用 18px 圆角和 26px 图标。标题 14px，说明 12px。
- 点击打开本地文件选择。仅展示名称和大小，不读取内容、不上传。
- 原生 file 输入覆盖可点击区域。键盘焦点轮廓包围选择区域。

### D06 文件列表 Upload list
- Standard 文件行 19px 圆角、12px 内衬。名称 12px、大小 11px。文件图标面 36×42px，移除按钮 32px 圆形。长文件名自然折行。
- 添加示例文件与移除均为局部操作。移除按钮包含文件名。
- Tab 访问每行移除动作。状态不得只用进度色表达。

### D07 拖放区域 Dropzone
- Standard 拖放区至少 208px 高，与上传区共享徽记和点击路径。拖入显示实线、主色浅底和徽记层次变化。
- 放下只接收名称和大小。每次最多展示八个本地文件。
- 无需拖动即可完成同一选择。拖出和完成后清除高亮。

### D08 文件夹选择 Folder picker
- Standard 容器 22px 圆角、16px 内衬。40px 文件夹行使用 12px 字号、12px 圆角。层级线连接下一级，选择保留浅色整行面。
- 展开根目录后选择目标。底部保留完整目标路径。
- 原生 details 支持 Enter/Space；子项按钮支持 Tab。只选择有授权的路径。

### D09 穿梭选择 Transfer
- 两个 Standard 列表使用 18px 圆角，最小高 186px。列表标题带实时数量，目标行至少 42px 高。中央操作为 38px 圆形，手机为 34px。
- 勾选后显式加入或移回。每次报告移动数量，取消勾选后进入另一侧。
- 操作不依赖拖动。需要搜索的大数据列表使用分页或虚拟列表。

### D10 级联选择 Cascader
- 至少 245px 的两级 Regular 弹层，以分隔线区分层级。叶子项至少 42px 高、13px 圆角、12px 字号。触发器展示完整平台路径。
- 选择供应系统后保留父层 pressed 状态并显示架构。选中叶子后关闭菜单。
- Tab 和 Enter 可完成全部层级。中间层不能冒充最终选择。

## 共同状态与材质

- 默认、悬停、焦点、按下、选中、禁用与错误均有独立表达。
- 正文输入使用 Standard。自定义菜单触发器和临时菜单使用 Regular；分裂与分段工具共用一层 Regular 外壳。
- 同类工具共享一层材质，不为组内按钮重复模糊。
- 活动滑块与开关强化玻璃反馈。空闲时恢复平静表面。
- 10px/210% 是 Regular 外壳的项目参数，不是 Apple 标准。
- 玻璃反光不覆盖文本。细弱色散只用于重要功能外缘。
- 减少动态效果关闭位移与过渡。普通模式菜单从触发器下方 240ms 展开，按压回应 320ms。关闭与状态写入不等待动画。
- 降低透明度使用实体底与清晰边界。高对比模式使用系统颜色。
- 手机输入字号 16px。菜单最大宽度受视口约束。
