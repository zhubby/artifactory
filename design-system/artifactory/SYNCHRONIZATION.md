# 原型与产品双向同步矩阵

核对日期：2026-11-27。此文件记录源码核对结果。
浏览器视觉验收单独记录，不以 CSS 存在判定完成。

## 同步规则

1. Apple Liquid Glass 是最高设计准则。
2. 原型提供视觉、布局和动效目标。
3. 当前 API、授权和数据来源决定真实行为。
4. 原型中不成立的字段，按真实契约反向修正。
5. Standard 承载正文、表格、日志和图表。
6. Regular 承载导航、浮层和重要工具组。
7. 主题、草稿、焦点和业务状态不得被动效重置。
8. 缺失证据、计数和状态不得用演示数据填充。
9. 概念扩展和组件标本不自动成为生产需求。

界面统一使用「工作空间」。底层 `tenant` 名称与 API 保留。
范围为账户 → 工作空间 → 项目 → 版本 → 构建。
选择或创建工作空间后，默认进入项目目录。
工作空间概览继续保留独立地址。

## 设置分区映射

真实设置由范围权限决定。项目管理员只操作项目范围。
工作空间成员保留自己的访问令牌入口。
归档、排空和删除中的工作空间与项目保持只读。
设置进入唯一分组侧栏，正文不再重复设置导航。
工作空间分区使用`#settings/{section}`。
项目分区使用`#project-settings/{id}/{section}`。
非管理员工作空间样例只提供访问令牌分区。
